# C04 · Story Keepsake

固定英文故事《The Welcome Star》的有限个性化、逐页校样、真实 PDF 与人工实体书订单记录。产品配置位于 `shared/products/c04.json`，Web 与移动入口均使用明确的表单字段。

## 已实现

- 原创固定八页故事，选择孩子名字、三种伙伴（fox/rabbit/owl）、三种地点（garden/forest/seaside）及献词。不使用 AI，不生成或上传照片。
- 每页可编辑标题与文本；服务端按实际 PDF 字体和版面尺寸检查排版容量，超长内容拒绝保存。英文及 Windows-1252 可表示的西欧字符可用于书中内容；其他字符给出明确错误。
- ReportLab 输出真实八页、612 × 612 pt 的 PDF。内置版式包含标题、正文、页码、校样版本和审批状态；未批准 PDF 明确标记待成人校对。所有文本传入排版器前转义。
- 成人必须填写姓名、当前校样版本，确认逐页检查后批准。审批绑定页内容摘要与版本。修改文字或重新个性化会提升版本、作废审批，并将未印刷订单标为 `proof_changed`。
- 录入客户、配送地址及数量（1–10 本）前必须批准当前校样，并由成人确认。订单保留所确认页面和审批快照。
- 打印完成记录要求当前订单与校样一致、实际印刷商名称、真实工单/收据编号和完成确认。进入印刷完成状态后该版书不能再改稿。
- 已印刷订单才能录入配送商、跟踪号和实际交接确认。只记录真实外部结果，不伪造打印或发货。
- 可选人工付款记录要求金额、币种、真实凭据编号和已实际收款确认，且禁止覆盖既有凭据。系统不会扣款或自行验证凭据。
- 未印刷订单可登记取消并保留原因、付款记录；重新下单时历史取消订单保留。取消不会执行退款。
- 可导出 PDF 校样和包含校样摘要、订单、地址及凭据的 TXT 交接文件。根层提供私有 JSON 备份。

## 操作顺序

1. 新建故事书并逐页阅读。需要时直接修改页面，或确认重置全部页面后重新个性化。
2. 下载当前 PDF，成人核对全部页面、拼写、献词与排版，批准当前版本。
3. 填写并确认订单地址与数量，下载订单交接文件；自行联系打印商确认纸张、装订、出血与价格。
4. 若已在外部收款，可记录对应凭据。实际印刷完成后录入印刷工单。
5. 实物交给承运人后记录配送商与跟踪号。

## 接口与限制

模块动作：`personalize`、`edit-page`、`approve-proof`、`place-order`、`record-payment`、`record-print`、`record-shipment`、`cancel-order`。导出：`pdf`、`txt`；根层负责身份隔离、revision 与 JSON。

当前交付的是 PDF 校样和人工履约账本。未接入印厂 API、支付处理、物流查询、自动邮件、照片或 AI 画图。默认 PDF 是方形阅读校样，打印商要求的出血、色彩配置、封套、装订及纸张需另行确认；不能将 PDF 下载当成已制作实体书。订单中的外部凭据是操作人员的人工申明，不代表系统已向供应商核验。

成年人姓名、地址与孩子名字默认私有；只在持有者明确导出后出现在交接文件中。固定故事支持有限个性化，重新套用故事会替换所有手工逐页修改。

## 验证

`backend/tests/test_products_b06_c04.py` 覆盖有限选项、页面编辑导致审批失效、过期或未成年审批拒绝、订单与印刷门槛、真实凭据/跟踪号要求、印刷后锁稿、付款记录、八页 PDF 和内容容量验证。PDF 另经 Poppler 页面渲染与文本提取核对。
