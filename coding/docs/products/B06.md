# B06 · Local Clean Pages

面向本地清洁商的英文站点构建、公开询盘及人工跟进流程。产品配置位于 `shared/products/b06.json`，Web 与移动入口共用业务字段。

## 已实现

- 输入真实商户名称、介绍、邮件、电话、营业时间、可选公开地址、逐行服务区域；逐条新增、编辑、删除服务与价格说明。
- 下载完整响应式 HTML 预览当前草稿。静态导出保留邮件与电话联系方式，可直接交给其他主机托管；离线导出不伪装成已接入后台的询盘表单。
- 显式确认后发布快照到 `/api/public/sites/{id}`。后续草稿编辑不改变公开版本；再次发布才替换快照。撤下页面后公开浏览与询盘均返回不可用。
- 公开页面使用原生 HTML 表单 POST `/api/public/sites/{id}/inquiries`。姓名、邮件、服务、区域、请求内容和联系同意均经服务端验证。服务和区域必须属于当前发布快照。
- 姓名、联系信息和询盘只对记录拥有者可见；不出现在公开页面。根路由处理访问控制、限速与通用成功响应。
- 可记录人工联系、报价、预约和关闭；逐条保留时间与跟进说明。不发送邮件或自动创建预约。
- CSV 询盘导出对潜在表格公式加文本前缀；HTML 中的所有业务文本与属性值均转义。CSS 内置，不依赖 JS、远程字体或图片。

## 操作顺序

1. 新建网站，添加至少一项清洁服务。
2. 下载 HTML 预览，核对公开资料。
3. 勾选公开确认并发布，打开公共链接。
4. 访客提交询盘后，在客户询盘列表中选择记录并填写跟进结果。
5. 更改服务或文案后重新发布；如需立即停用，使用撤下按钮。

## 接口与限制

模块支持 `update-site`、`add-service`、`update-service`、`remove-service`、`publish`、`unpublish`、`follow-up`，以及 `html`、`csv` 导出。根层提供 JSON 备份、授权、并发 revision 验证和持久化。

发布位置是当前应用服务的公共路径。自定义域名、SMTP 通知、反垃圾服务、客户管理系统、支付与预约系统尚未接入。公开页面表单需要同源后台；将下载的静态 HTML 放到其他主机时使用其邮件/电话联系入口。

业务上限为 20 项服务、30 个区域、每站 10,000 条询盘。输入限制与公开联系同意在服务端执行。限速由根公共路由处理，运营部署仍需按访问规模配置。
