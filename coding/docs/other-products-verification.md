## 独立审查与修复

并行实现后进行交叉审查，再执行一次集中修复和定向复核。已修复并复核的后端问题：关闭工单处理凭据丢失、来源端口/控制字符校验、可导出却不能恢复的大备份、超长 CSV 数字造成异常、取消日历误导入、ISBN 输入与搜索形式不一致。公共网关额外拒绝非法 Unicode，JSON 备份采用紧凑编码，文本导入与服务端限制对齐。

网页连续保存旧值回填的问题已通过成功后重建表单解决；失败时不会重建，输入保留。移动端同步与退出账号并发、待同步备份内容及清单状态修复已由独立审查复核，并通过延迟请求/排队写入回归与真实浏览器离线流程。启动时 401 也会先识别旧账号并清理缓存，再删除账号概要。定向复核未留下未处理的高/中等级问题。

## 明确边界

1. B01 是带来源的确定性词法检索助手，B09 是经核实事实的模板草稿；当前没有生成式模型、网页抓取、客服平台或邮件发送接入。
2. C04 是固定故事校样与真实凭据履约台账。没有在线收款、实际印刷服务或物流接口；PDF 不代表实物已经印刷/送达。
3. B06 发布到当前服务的公开 URL，生产域名、HTTPS、基础设施和获客未在本机验收中发生。
4. 移动端代码及 JS/Hermes 导出不等同于 iOS/Android 签名安装包。当前环境无原生 SDK/真机，原生签名、设备兼容和商店发布待实际账户与设备验收。
5. 浏览器移动预览的断网验证从已加载的应用进行，另模拟 API 不可达后的缓存会话恢复；未实现浏览器完全离线从零加载的 PWA。原生应用使用安装包中的应用代码和私有文档缓存。
6. 单实例 SQLite + 本地文件。Docker 部署配置存在，但本机没有 Docker，未声称已部署或完成容器运行验收。现有 Expo 间接构建依赖中的 moderate 级 uuid 问题仍记录于 B04 验收文档；本次新增业务无额外前端运行库。
