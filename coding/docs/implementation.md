# Episode Desk V1 实施计划

> 采用子代理并行开发；主任务集成、检查接口与独立复核。承接已确认的 OS-B04 需求，不重新启动旧海外10项。

**目标：** 将已确认的审稿原型实现为可本地启动、可部署的三端协作产品，完成真实身份、持久化、文件管理、版本审稿和交付签收。

**架构：** backend 为 Python 3.12 / FastAPI / SQLite 单实例服务，文件保存于私有数据目录；frontend 为 React / TypeScript / Vite；app 为 Expo / React Native / TypeScript。三端共用 REST 协议。开发目录在仓库根 coding，使用独立开发分支，保持用户指定路径。

**需求基线：** ../../AI创业调研-StarterStory/09-实施方案/海外市场/独立选题重建/项目方案/OS-B04-英语播客成品包/06-产品需求与版本规划/03-产品需求说明书.md

## 交付范围

- 编辑注册工作室；邀请客户；真实账号登录/注销，服务端会话、密码散列、客户订单隔离。
- 一期完整简报、源授权、三片段、开工检查、7自然日交期、逐片审核、整包修订和历史。
- 同一期重开简报更换素材，所有批准失效并重新授权、确认开工。
- 私有源文件及成品上传、下载，成品绑定版本和片段；验证MP4时长/9:16/音视频轨、SRT语法和区间；人工质检确认后才交付，客户真实签收。
- 导出审稿清单与工作文案、服务器备份恢复命令、完整运行与部署说明。
- 英语界面。网页承担全工作流；移动端优先客户简报、审稿、签收，也支持编辑核心动作。
- 人工剪辑/转写仍使用现有工具；不伪造AI渲染、邮件发送、收费和商店发布。交付文件不是占位下载。

## 重点失败场景

1. 客户A猜测客户B的订单和文件ID，必须404/403。
2. 客户在旧版页面批准，或双端并发修改，必须409且无状态污染。
3. 文案获批但缺少真实视频/字幕或质检，不能交付；新修订使旧文件失效。
4. 网络/磁盘/上传失败，表单保留并显示可恢复错误，不显示完成。
5. 无授权或更换源素材，不能复用旧批准、开工时间或文件。
