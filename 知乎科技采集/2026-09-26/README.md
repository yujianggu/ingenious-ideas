## 数据边界

这是首批搜索结果索引与摘要采集，不是全文库；未逐篇获取正文、评论正文、图片或付费内容。摘要是搜索卡片文本的截选，可能不是原文开头。AI 第一组人工选取短片段，其他组截取前55个字符。raw 目录保存这些经过字段整理和短摘录截选的逐关键词观察，不是网页完整快照。

没有发布时间限制，默认综合排序。日期仅有月日时不推断年份，相对日期也不换算；页面没有说明它是发布日还是更新日。“万”数值属于近似显示，“添加评论”不转为已核实的零评论。

内容类型和风险提示只依据标题与短摘录。来源中涉及薪资、收益、市场份额、产品能力、新闻或政策的说法均未独立事实核查。报告数量矛盾、标题日期差异等已标记；不要把这些摘录直接当作可靠事实发布。
