# 跨企业专题

本目录用于比较多个企业或机构对同一经营问题的不同解法。当前覆盖 9 个对象的第一轮档案与第二轮经营详解、案例补充，比较结果仍属于待验证命题，不构成因果结论。

## 已有专题

- [企业数字化：IPD、BRM 与 4A 架构](企业数字化-IPD-BRM与4A/README.md)：区分产品开发机制、业务参考模型与企业架构，含教学场景与来源边界。
- [案例导航](案例导航.md)：按企业、经营问题与反例定位第二轮案例。
- [经营数据口径与比较边界](经营数据口径与比较边界.md)：区分分析单位、数据定义与迁移条件。

- [经营机制比较](经营机制比较.md)：比较客户价值、反馈周期、资本配置、知识沉淀、组织边界与主要风险。
