# 华为经营研究

第二轮补充：2026-09-26。[摘要](摘要.md) · [经营详解](经营详解.md) · [案例](案例.md) · [补充来源与证据边界](来源.md)。下方保留第一轮研究；新增分析及数据口径以补充页明确的观察期为准。


研究日期：2026-09-21。状态：第一轮公开资料研究。

本轮研究华为如何经营自身，重点覆盖业务组合、研发投入、治理与激励、管理经验沉淀。财务数据主要来自经毕马威审计的 2025 年合并财务报表；经营理念、治理说明与案例主要是公司自述，不能单独作为效果的因果证据。[S1][S5]

## 初步判断

**研究推断：**华为值得研究的，不只是“重视研发”，而是它试图把长期技术投入、多业务组合、员工利益安排和集体治理连接成一个持续经营系统。这个系统在资本密集、技术迭代快、全球经营复杂的行业更有研究价值；其成本、组织压力和外部条件也很高，不能压缩成口号直接移植。

## 一、经营模式

2025 年，华为收入为 8,809.41 亿元、净利润为 680.36 亿元、经营活动现金流为 1,273.84 亿元。收入来自 ICT 基础设施、终端、云计算、数字能源、智能汽车解决方案及其他业务；前两项分别贡献 3,750.14 亿元和 3,444.73 亿元。中国市场收入为 6,162.49 亿元，约占总收入 70%。[S1]

| 经营问题 | 已披露机制 | 研究分析 |
|---|---|---|
| 如何创造收入 | 同时服务运营商、政企客户和消费者，销售设备、软件、服务及行业解决方案 [S1] | 多类客户与产品可共享技术底座，也增加组合管理难度 |
| 如何保持技术供给 | 2025 年研发费用 1,923 亿元，占收入 21.8%；研发人员约 11.4 万人，占员工 53.7% [S1] | 高投入扩大长期选择权，但投入额本身不证明研发效率 |
| 如何形成生态 | 围绕昇腾、鲲鹏、鸿蒙及云服务吸引开发者和伙伴 [S1] | 竞争单位从单品延伸到技术平台和互补者网络 |
| 如何筹集和分配长期资本 | 公司披露其由员工及退休受益人持有，并实行贡献与分享相结合的激励安排 [S3][S4] | 利益安排可能支持长期投入；实际激励效果仍需员工流动、回报分配等证据验证 |

**研究推断：**华为的组合不是无关多元化。联接、计算、云、终端、数字能源和汽车解决方案之间存在芯片、软件、工程能力、渠道或生态关系。但“存在协同可能”不等于已经实现协同，需逐项核算共用能力、内部交易和资源争夺。

## 二、关键机制与实践

### 1. 把长期研发投入制度化

公司称坚持每年将销售收入的 10% 以上投入研发；2025 年实际比例为 21.8%，近十年累计研发费用超过 1.382 万亿元。[S1]

**研究分析：**固定的投入承诺有助于减少短期利润波动对长期研发的挤压。判断其质量仍应追踪三个结果：技术是否转化为客户采用，是否形成可持续收入与现金流，以及是否减少关键能力约束。专利数量和研发占比只能作为投入或中间产出指标。

### 2. 以客户价值统领治理与管理

华为将“以客户为中心、为客户创造价值”表述为共同价值，并把董事会定位为公司战略、经营管理和客户满意度的最高责任机构。[S2] 这是公司的治理原则与自我描述，不等于客户价值已经自动实现。

2025 年年报披露，公司通过客户满意度与伙伴体系健康度的日常声音处理、评估和改进形成两个闭环；在质量管理中使用 TRIZ、FMEA 等方法，并加强知识管理与项目复盘。[S1]

**可迁移问题：**客户意见如何进入流程、形成责任人、落实改进并被复核？“客户导向”只有转成可观察的闭环，才可能成为经营机制。

### 3. 集体治理与轮值安排

公司治理页披露：法律层面的股东会由工会与任正非两名股东组成；持股员工代表会代表持股员工行使相关权利。2025 年有 127,909 名享有选举权的持股员工参加代表选举，产生 161 名代表。董事会及其常务委员会由轮值董事长主持，每届轮值任期六个月。[S2]

公司另披露，截至 2025 年末，华为投资控股由 169,054 名员工和退休受益人持有，任正非出资占总股本约 0.59%。[S3]

**证据说明：**以上是华为对其持股和治理结构的披露。“员工和退休受益人持有”与“股东会由工会和任正非组成”分别描述受益安排与法律治理结构，不应简化为每名员工都是工商登记中的直接股东。本轮尚未取得可独立核对全部受益人、份额变化及退出安排的公开登记资料。

### 4. 按业务阶段实施差异化激励

2025 年报称，华为继续实施基于责任履行结果的“贡献与分享”机制，并按业务、发展阶段及员工群体差异化配置激励，资源向一线和高挑战岗位倾斜。[S4]

**研究推断：**这体现的不是统一薪酬公式，而是让资源配置跟随经营责任和业务阶段。其风险是评价权集中、跨业务比较困难，以及短期可量化贡献可能挤压基础性工作；公开资料不足以评价这些风险如何被控制。

## 三、经验如何沉淀为组织能力

本轮资料显示出四种载体：共同价值用于规定判断方向；流程与内控用于明确责任和监督；质量工程方法用于处理重复问题；知识管理、复盘和培训用于传播经验。[S1][S2]

公司监事会称，其目标之一是推动管理“从基于经验走向基于规则”；公司同时设置风险评估、流程责任人沟通、内审和问责机制。[S2]

**研究归纳：**现场问题 → 方法化解决 → 项目复盘与知识记录 → 纳入流程、培训和问责 → 再由经营结果检验。是否真正形成有效学习循环，还需观察失败案例能否公开进入复盘、旧规则能否及时退出。

## 四、反面证据与局限

- **经营结果并不平滑。**公司披露的营业利润率在 2021—2025 年分别为 19.1%、6.6%、14.8%、9.2% 和 11.0%；这说明高研发与长期主义并不会消除利润波动。[S1]
- **业务分化明显。**2025 年智能汽车解决方案收入增长 72.1%，云计算分部收入下降 3.5%。组合可以分散部分风险，也可能掩盖业务质量差异。[S1]
- **地域集中仍高。**2025 年约 70% 收入来自中国。由此推断，公司对单一区域的需求、竞争和政策环境仍有较高暴露；年报数据本身不能说明这种集中必然有利或有害。[S1]
- **投入不等于产出。**研发费用、人员和专利数量能够证明资源投入，不能独立证明商业化效率或技术领先的持续时间。
- **披露边界。**华为不是上市公司。本轮虽使用经独立审计的财务报表，但治理、文化和管理成效主要来自公司材料，缺少与员工、客户、供应商及失败项目的系统性对照。

## 五、适用边界与下一步

较可能适用于：技术周期长、需要持续研发、可以复用技术平台、组织规模足以建设专业流程的企业。谨慎用于：现金流脆弱的早期企业、技术依赖较低的本地服务业，以及无法承受长期投入和复杂治理成本的组织。

下一轮优先工作：

1. 选取终端、云、数字能源和汽车解决方案，分别检验组合协同与内部资源配置。
2. 对照 2019—2022 年的外部冲击，复原供应链、产品与区域结构调整的时间线。
3. 补充员工持股退出、分红、虚拟受限股及长期激励的制度材料与独立研究。
4. 寻找客户项目失败、研发沉没成本和组织调整案例，避免只研究成功叙事。
