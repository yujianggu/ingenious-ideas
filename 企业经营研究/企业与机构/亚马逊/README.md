# 亚马逊经营研究

第二轮补充：2026-09-26。[摘要](摘要.md) · [经营详解](经营详解.md) · [案例](案例.md) · [补充来源与证据边界](来源.md)。下方保留第一轮研究；新增分析及数据口径以补充页明确的观察期为准。


研究日期：2026-09-21。状态：第一轮公开资料研究。

研究范围包括亚马逊如何把零售、第三方卖家、物流、会员、广告和云服务组合成多业务系统，以及客户导向、长期投入和快速决策如何被制度化。本轮以 SEC 文件、股东信、公司流程说明及监管文件为主。

## 初步判断

**研究推断：**亚马逊最值得研究的，是它如何把“客户价值”从理念变为一组投资和决策机制：围绕选择、价格、便利和可靠性建设基础设施，再把基础能力开放给卖家和企业客户，形成新的服务收入。

这套模式的另一面是极高的资本需求、组织复杂度和平台权力。2025 年 AWS 贡献了集团过半经营利润，而资本开支增长使自由现金流显著下降；监管和劳动争议也表明，“客户至上”不能替代对卖家、员工和竞争秩序的约束。[S1][S10][S11]

## 一、经营模式

亚马逊在法定披露中将业务分为北美、国际和 AWS 三个报告分部，但收入来源跨越线上与实体零售、第三方卖家服务、广告、订阅和云服务。[S1]

| 收入与能力 | 2025 年可核实事实 | 经营作用 |
|---|---:|---|
| 线上商店 | 2,692.87 亿美元收入 | 自营商品与数字内容带来交易规模 |
| 第三方卖家服务 | 1,721.62 亿美元收入 | 佣金、履约和配送费把平台流量与物流能力服务化 |
| 广告 | 686.35 亿美元收入 | 将站内购买意图变现 |
| 订阅 | 496.19 亿美元收入 | Prime 等会员提高复购和生态黏性 |
| AWS | 1,287.25 亿美元收入；456.06 亿美元经营利润 | 将内部技术基础设施外部化，成为主要利润来源 |

2025 年集团净销售额为 7,169.24 亿美元，经营利润为 799.75 亿美元；AWS 经营利润约占集团的 57%。以上均为公司报告分部口径，不能等同于各业务的独立经济价值。[S1]

**研究推断：**其经营循环可表示为：更丰富的选择和更好体验吸引客户 → 客户流量吸引卖家 → 卖家增加选择并分担库存 → 规模支持更低单位成本和更快配送 → Prime 提高使用频率 → 交易数据与流量支持广告和新服务。AWS 则是“把内部共性能力产品化”的另一条增长曲线。

这是一种机制解释，不是已独立验证的单一飞轮。各环节也可能发生利益冲突，例如广告增加收入，却可能降低搜索相关性；平台物流提高便利，也可能增强卖家依赖。[S10]

## 二、关键机制与实践

### 1. 长期主义与可衡量投入

1997 年股东信明确提出：以长期股东价值而非短期利润作决策，围绕客户与收入增长、复购和品牌衡量市场地位；分析投资效果，停止不能产生可接受回报的项目，并加大有效项目投入。[S2]

**研究分析：**亚马逊的长期主义并非“长期项目永不退出”，而是允许较长验证周期，同时要求用经营证据重新配置资本。2022 年后，公司逐项审查业务的收入、经营利润、自由现金流和资本回报潜力，并重构履约网络，说明长期主义仍需退出和纠偏机制。[S7]

### 2. 从客户倒推：PR/FAQ

亚马逊公开的流程说明称，团队先写面向客户的新闻稿与常见问题，定义客户体验、价值、成本和未解决问题，再决定是否投入开发；文档通常多轮修改，只有少数方案获准。[S3]

**证据性质：**该材料摘自两名前员工著作，由亚马逊官网转载，能说明内部流程及公司认可程度，不能单独证明 PR/FAQ 提高创新成功率。

**研究分析：**它把模糊创意提前转化为可争论的客户价值和假设，降低“先开发再找用途”的风险。边界是团队可能写出有说服力但证据不足的叙事，因此仍需原型、客户行为和单位经济性验证。

### 3. 高速度决策：单向门与双向门

Bezos 将难以逆转的重大决策称为单向门，需要谨慎；多数可逆决策属于双向门，应由有判断力的个人或小团队快速作出。2016 年股东信又把客户导向、警惕代理指标、采用外部趋势和高速度决策列为抵御“大公司迟缓”的方法。[S4]

**研究分析：**关键不是一味加速，而是先判断可逆性、损失上限和客户影响。若把不可逆的安全、劳动、隐私或合规决策误判为双向门，速度会放大风险。

### 4. 将内部能力变成“基础组件”

公司披露显示，FBA 让卖家使用亚马逊仓储和配送；后续又将跨境运输、仓储、末端配送和多渠道履约等能力对外提供。AWS 同样将计算、存储和数据库能力作为服务销售。[S1][S8]

**研究推断：**亚马逊扩张的一条主线是：先为自身规模问题建设通用能力，再将能力模块化并出售给外部客户。这比进入完全无关业务更可能复用技术、固定资产和运营知识；但也会形成平台既参与交易又制定规则的冲突。

### 5. 运营网络的持续重构

疫情期间亚马逊在约两年内将履约中心占地规模扩大一倍，随后发现生产率和成本仍需优化。2022—2023 年，公司把美国全国性网络改为八个互联区域，通过更靠近需求的库存配置减少运输距离；公司报告称 2023 年全球单件履约成本自 2018 年以来首次下降。[S7][S8]

该案例说明规模建设之后仍需重新设计网络。公司披露的改善与同期需求、价格和会计因素可能共同作用，不能仅凭管理层叙述归因于区域化。

## 三、经验如何沉淀

| 沉淀方式 | 公开机制 | 可迁移的认识 |
|---|---|---|
| 原则化 | 16 项 Leadership Principles 用于日常决策、招聘与领导行为 [S5] | 文化要进入选人、评价与争论语言 |
| 文档化 | PR/FAQ 从客户体验倒推产品 [S3] | 在投入前写清对象、价值、约束和证据 |
| 决策分类 | 单向门与双向门匹配不同决策强度 [S4] | 流程成本应与不可逆性和风险相称 |
| 机制化 | 公司反复强调可控的输入指标、深入细节和运营复盘 [S1][S5] | 原则需落到指标、负责人和固定节奏 |
| 复用化 | FBA、AWS 等把内部能力开放给外部客户 [S1][S8] | 共性能力可从成本中心变成产品 |
| 失败学习 | 2018 年股东信称 Fire Phone 失败后的人员和经验转向 Echo/Alexa [S6] | 失败价值来自可回收资产与明确学习，不来自失败本身 |

## 四、反面证据与局限

### 客户导向与消费者操纵之间的冲突

**事实：**2025 年，亚马逊与美国联邦贸易委员会就 Prime 注册和取消流程达成 25 亿美元和解，包括 10 亿美元民事罚款和 15 亿美元消费者补偿，并被要求改变相关界面和取消流程。2026 年监管机构披露，亚马逊已发放超过 8.45 亿美元补偿。[S11]

这不是一般性的“监管指控”，而是法院批准的和解及后续执行。它表明，一项提升转化率或降低流失的内部机制可能损害客户自主选择；“客户痴迷”必须由可审计的消费者保护指标约束。

### 平台协同与平台权力之间的冲突

**事实：**FTC 与多州于 2023 年起诉亚马逊，指控其通过反折扣措施和 Prime/FBA 绑定等行为非法维持垄断。该案属于尚待法院裁判的指控，不能写成已认定违法事实。[S10]

**研究分析：**同一套平台机制既能降低搜索、交易和履约成本，也能提高卖家的迁移成本并让平台影响价格、展示和配送选择。评价平台经营不能只看消费者当期便利，还需观察卖家抽成、创新空间和可替代渠道。

### 规模化试验的成本

2018 年股东信主张，大公司应允许与规模相称的失败，并以 Fire Phone 为例。[S6] 这代表管理层的资本配置理念，而非“失败越大越好”的证据。适用前提包括：投资组合足够分散、失败不会造成不可逆安全或合规伤害、能设止损点，并能回收人才、技术或认知。

### 财务与组织边界

- **利润结构集中：**2025 年 AWS 贡献集团约 57% 的经营利润，零售规模不能直接等同于利润质量。[S1]
- **资本强度：**2025 年自由现金流降至 112 亿美元，主要因物业与设备净购置同比增加 507 亿美元；AI、数据中心和物流投资会压缩短期现金并提高预测错误成本。[S9]
- **指标冲突：**速度、节俭、高标准和深入细节之间存在内在张力；Leadership Principles 提供共同语言，但不能自动解决权力、资源和激励冲突。[S5]
- **公司叙事偏差：**股东信擅长解释成功机制，也存在幸存者偏差；需补充被关闭项目、员工、卖家和监管证据。

## 五、适用边界

亚马逊经验更适合市场空间大、客户行为可快速反馈、基础能力可被多个业务复用，并且组织能够承担多年资本投入的企业。较小企业可以学习“从客户倒推”“区分可逆决策”和“将共性能力模块化”，但不应照搬其资本投入、亏损周期和平台扩张范围。

采用这些方法时，应同时设置三类约束：客户结果不能只用转化率表示；长期投资要有阶段性证据和退出条件；平台协同要评估对卖家、员工、竞争与监管的外部成本。

## 六、下一步

- 按 Prime、Marketplace/FBA、AWS、广告四条业务线重建关键年份、投入、失败与现金流时间线。
- 补充 Fire Phone、Amazon Restaurants、实体店调整等退出案例，分析止损机制而非只看赢家。
- 研究卖家费率、搜索广告占比和履约绑定，检验平台飞轮中价值创造与价值攫取的变化。
