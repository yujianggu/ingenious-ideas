# 企业经营调研框架

## 研究目标

形成有案例支撑、有逻辑解释、有适用边界的企业经营认知体系。既理解企业做了什么，也理解为什么这样做、为何可能有效，以及何时可能失效。

研究对象包括不同企业，以及 YC 这类能够提供经营实践与方法论样本的机构。不预设所有企业都应追求相同的增长速度、融资方式或组织形态。

## 六个研究维度

| 维度 | 核心问题 |
|---|---|
| 经营理念与底层逻辑 | 为谁创造价值？使命、价值观和经营原则如何进入真实决策？ |
| 战略与商业模式 | 如何选择市场、配置资源、盈利、形成优势和决定业务边界？ |
| 组织与管理机制 | 如何通过治理、人才、激励、文化与流程实现战略？ |
| 经营实践与关键决策 | 在创立、成长、扩张、危机和转型中作出了什么选择？ |
| 经验沉淀与理论形成 | 如何把个人经验转化为原则、制度、工具和组织知识？与既有理论有何联系？ |
| 适用条件与局限 | 哪些认识可迁移？哪些依赖行业、时代、阶段、资源或领导者？ |

## 单个对象的记录结构

1. **基本信息与研究范围**：对象类型、研究时间、资料覆盖与缺口。
2. **经营模式**：服务对象、价值创造、价值获取、关键资源与成本约束。
3. **关键实践案例**：背景、问题、可选方案、决策、执行、结果与证据。
4. **经验与方法**：当事人如何总结，研究者如何解释，有无相反证据。
5. **知识沉淀机制**：经验如何被记录、传播、训练、复用与修订。
6. **适用边界与待验证问题**：哪些结论仍是推测，下一步需要什么证据。
7. **资料来源**：标题、作者或机构、发布日期（可得时）、链接、核对日期。

## 案例分析卡

| 字段 | 记录内容 |
|---|---|
| 背景与阶段 | 当时的市场环境、企业阶段和资源约束 |
| 经营问题 | 要解决什么问题，如何识别它 |
| 选择与取舍 | 有哪些方案，为何选择该方案，放弃了什么 |
| 执行机制 | 谁负责、如何行动、资源投入与反馈周期 |
| 实际结果 | 可观察结果、观察时间和未达到的目标 |
| 原始解释 | 当事人对成败原因的解释 |
| 研究分析 | 可能机制、替代解释、能否支持因果判断 |
| 适用边界 | 前提、代价、反例及不可直接复制的条件 |
| 来源与缺口 | 证据链接、日期和仍待核实的信息 |

## 跨企业比较方式

围绕同一个经营问题比较不同解法，而不是仅比较口号。例如：同样面对增长放缓，不同企业选择改善产品、调整客户群、降本还是开辟新业务？这些选择与其资源和阶段有何关系？

比较时至少检查：目标是否一致、业务类型是否相近、发展阶段是否可比、外部环境是否不同、结果指标和观察窗口是否一致。

## 证据规则

- **事实**：来源可核查的事件、机制或数字；企业自报数据注明性质。
- **当事人主张**：保留提出者与历史语境，不自动提升为通用规律。
- **研究推断**：说明依据、可能机制和替代解释。
- **待验证命题**：写清需要补充的样本、数据或反例。
- 优先原始文章、官方公告、财报及当事人访谈；官方材料同样可能存在选择性呈现。
- 估值不等于实际投资回报，增长不等于盈利，相关性不等于因果关系。
- 历史经验与现行机制分开记录；没有结果证据时，不将一次决策描述为已证实成功。

## 第二轮资料的深度要求（2026-09-26）

单家企业使用分层文件，避免一份入口承载所有研究：

- `摘要.md`：回答研究什么、最重要的经营机制及不能直接复制的前提。
- `经营详解.md`：解释客户、价值创造、收入成本、经营数据、组织决策、资源配置和风险。
- `案例.md`：展开真实事件及执行过程；至少纳入一个失败、治理或机制边界案例。
- `README.md`：保留第一轮历史档案和来源，并提供新增资料导航。第一轮中的时间表述只适用于其原查阅日期；后续核验更正需明确标记。

“详细”不以重复口号或增加篇幅衡量，而以是否能回答以下问题衡量：谁拥有决策权、依据什么信息、选择了什么、放弃了什么、如何执行、在哪个时间窗口观察到什么结果，以及还有哪些解释。

## 经营数据的口径检查

| 数据类型 | 必须记录 | 常见误读 |
|---|---|---|
| 营收与利润 | 财年起止、币种、单位、合并／分部、持续／终止经营、是否经重述 | 将财年当自然年，或把总营收当产品收入 |
| 增长 | 基期、同比／复合增长、报告／固定汇率、有机／并购贡献 | 用并购后的规模增长证明原业务竞争力增强 |
| 自由现金流 | 企业所用定义、资本支出口径、租赁支付或并购是否包含 | 跨公司直接比较同名但不同定义的 FCF |
| 投入 | 研发费用、资本化项目、资本支出、承诺或已支付 | 将支出承诺当成当年实际投资，将研发与资本开支相加但未排重 |
| 客户与会员 | 付费账户／家庭／持卡人、活跃／累计、续费率分母与滞后期 | 用总人数推导客单价，或把续费率当全体用户即时留存 |
| 收购与投资 | 公告／完成日期、股权／企业价值、现金／债务、持股与稀释 | 将收购对价等同于减值，或将估值等同于已实现收益 |
| 现金与风险 | 报告主体、受限资金、债务、保险负债和未交割交易 | 把受托或负债对应资金当可随意分配的闲置现金 |
| 经营效率 | 地区、渠道、业务范围、价格与产品组合、计算方法 | 用全公司利润变化单独证明某项改善措施有效 |

不同财年和币种可以并列作为背景，不能在缺少调整时形成排名。比率由本库计算时，应写出公式、来源数字和舍入规则；不确定计算口径时保留原始披露，不补造可比值。

## 案例证据与分析的分离

1. **结果先定观察窗口。** “项目推出”“交易完成”“监管批准”属于里程碑；收益兑现、用户持续采用或风险降低需要后续证据。
2. **公司主张保留归属。** 公司称效率提升，可证明其作出该披露；缺少独立测量时，不改写成经独立验证的效果。
3. **失败分清层次。** 产品退出、财务减值、战略收缩和违法裁决不是同一种结果。指控、和解、行政认定与生效裁判分别记录。
4. **替代解释要具体。** 比如需求周期、汇率、并购、提价、疫情恢复、会计口径或竞争者退出，不只写“可能有其他原因”。
5. **不能观察的过程不编造。** 无内部资料时，不虚构会议过程、个人动机、具体考核办法或当时管理层考虑过的备选方案。研究者提出的备选必须明确标为反事实分析。
6. **迁移以条件为单位。** 迁移“异常暴露后的处置权限和复查机制”，比迁移一句“精益文化”更容易验证；同时检查执行成本和负面指标。

## 来源核对与维护

每次补充标注核查日与资料对应期，优先使用财报、监管材料、公司原始文章和当事人记录；动态网页的当前内容不能自动代表事件发生时的规则。无法读取全文时，说明依据来自摘要、官方检索结果或其他可核实材料，不声称已经通读原文。

本轮研究采用能够明确核验的资料窗口，不宣称所有字段均为最新状态。需要作实际决策时，对投资条款、产品供给、管理人员、财务数据及诉讼进展重新核验。缺失数据应记为“未取得”，不把未知写成零，也不把未找到负面证据写成不存在问题。
