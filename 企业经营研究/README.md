# 企业经营研究

系统调研不同企业与经营机构的经营之道，以及它们在实践中沉淀的经验、方法与理论。通过跨企业、跨行业和跨发展阶段的比较，理解企业如何创造价值、建立竞争优势并持续发展。

本研究不限定于一家公司。当前覆盖九个对象；研究沿用统一框架，同时保留各对象的业务特点与适用条件。

## 维护原则

- 企业数字化概念与教学分析见 [IPD、BRM 与 4A 架构](跨企业专题/企业数字化-IPD-BRM与4A/README.md)，与企业事实研究分别标注。
- 企业事实、当事人主张、研究者推断分别标注。
- 关键事实保留原始来源；易变信息标注核对日期。
- 成功与失败都纳入研究，不把成功故事直接当成因果证明。
- 通用结论进入跨企业专题前，先检验行业、阶段、资源和制度条件。
- 尚未研究的对象不预填结论；新对象使用独立目录并加入索引。
