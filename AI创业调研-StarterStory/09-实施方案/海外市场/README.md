## 本版判断

没有现成渠道时，先研究B16的流程差异和C13的本地工具差异；若有当地招聘顾问，C01可先做服务试单；若有数据能力和相同平台客户，B10可优先。此顺序是研究成本判断，不是确定商业赢家。B16的基准获客覆盖期偏长，不能沿用国内主选地位直接开发。

C16／C18的低价买断在欧洲人工压力情境下余量很薄；B12／B18／B17先找行业伙伴再投入。先完成一个国家、一个创意、一个付费闭环，再考虑第二语言。
