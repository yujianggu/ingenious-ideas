# OS-B04 产品需求说明书

版本：1.1｜2026-09-20｜状态：已按app.js/logic.js静态核对；浏览器实测见检查记录；未收费验证。

## 1. 产品与商业边界

为美国英语、2–5人的访谈/播客制作工作室提供人工编辑成品服务：将一期已经完成长片编辑、长度不超过60分钟的授权素材，转成3个30–90秒的9:16片段、对应SRT、章节摘要、3条宣传文案和验收记录。含1轮合并修订，暂测 **$240/期**；7个自然日从“素材齐备并确认可开工”的时间起算。买家、价格、工时和复购均待验证，非新剪辑SaaS。

[B2B候选核查](../../../研究/B2B候选核查.md)提供选题依据；本说明书以$240单期范围作验证假设。首次真实收费前必须核实英语专业编辑能力、内容使用授权与实际收款可行性。原型不替用户完成这些核实。

交付承诺不含录制、长片精剪、无限修改、社交账号代发、曝光/转化承诺或自动AI剪辑。客户改选新的长片素材或扩展片数，需要另行确认范围与交期。7个自然日包含客户按约及时反馈的前提；实际合同须约定审稿时限、暂停与重新排期，不能在界面静默改交期。

## 2. 角色和入口

- 客户：提供episode信息、品牌词表、禁用声明、素材引用和授权确认；逐片批准或填写理由退回；接收正式成品。
- 编辑：检查素材、核对原话与上下文、提交3段审稿、处理合并修订、准备生产交付清单。
- 原型：角色切换用于演示，不是身份认证。资料只在当前浏览器持久保存，可下载备份；切换角色不构成真实客户签字。

## 3. 最小业务流程

客户建一期任务并确认授权 → 编辑确认素材齐备 → 编辑录入3片段及回听结果 → 提交客户评审 → 客户逐片批准/有理由退回 → 编辑创建新版本修订并再次回听 → 对当前版本重审 → 当前3段全部批准 → 准备交付清单 → 正式生产补齐并验收全部成品 → 交付。

“全部审稿通过”只代表文字选段与上下文获批准。“准备交付清单”不代表已渲染视频。“已交付”只用于正式生产有完整实物文件与交付证据的阶段，原型不得以按钮或示例下载伪造该状态。

## 4. 字段和校验

| 对象 | 必填/结构 | 校验和失败反馈 |
|---|---|---|
| Episode | 稳定ID、标题、工作室/品牌、原素材时长、素材引用、术语表、品牌/上下文备注、授权确认 | 标题/品牌/素材引用不得为空；原型时长为90–3600整数秒。英语是业务范围，无语言选择字段；词表和备注允许空白。正式生产需明确禁用声明，建议无要求也写None |
| 授权 | rights布尔值、提交brief事件时间、素材引用 | 未确认不能提交brief；同一期brief提交后冻结，原型没有重开或替换源素材流程。正式生产换源需重新授权；本地确认不等于合同或权利调查 |
| 素材齐备 | 正式生产待建：确认时刻、素材可访问/音画可用、范围确认 | 原型没有readyAt或真实素材齐备验收；提交brief不等于开工。填URL本身不证明齐备；不自行联网读取 |
| 片段×3 | 固定slot/独立ID、开始秒、结束秒、逐段原话、上下文解释、标题、宣传文案、回听核对 | 0≤开始<结束≤素材时长；30≤结束−开始≤90秒；所有文本去空白后非空；回听未确认不能送审 |
| Review | 片段ID、整包版本号、批准/退回、理由；事件记录动作与时间 | 退回理由必填；仅评审中当前版本可操作；过期版本不能被新批准 |
| Revision | 整包version递增、前一版送审快照及决定、活动事件 | Start new revision清空三段全部批准和回听、清除manifest；旧快照保留。没有逐片版本号或parentId字段 |
| Delivery item | 类型、关联片段/版本、文件名/位置、校验记录、准备状态 | 原型manifest记录缺失生产资产，无真实文件核验字段；正式生产必须逐文件核验，清单不能替代文件存在 |

原型时间输入为整数秒，界面显示单位；不接受NaN、无穷值、负值、空值。区间允许首尾相接；原型未实现片段重叠检测；是否重叠由编辑判断，不是自动验收条件。原话是选中范围的内容，不能把删改后的营销句冒充逐字转录。

## 5. 15项可追踪需求

| ID | 需求 | 实现边界 |
|---|---|---|
| R01 | 多episode创建、切换并各自保存资料和状态 | 原型；不允许跨episode审批串用 |
| R02 | 收集素材、品牌、备注和授权；校验标题/品牌/素材/时长/授权 | 原型允许备注/词表为空；禁用声明及真实验源是生产闸门 |
| R03 | 每期恰好3段，时间范围及30–90秒校验 | 原型 |
| R04 | 每段具备原话、上下文、标题、文案、回听确认 | 原型记录；真实回听是人工责任 |
| R05 | 仅符合条件的整包可送审，提交固定版本 | 原型 |
| R06 | 客户逐片批准/有理由退回，不能批准旧版 | 原型角色演示；生产身份鉴别另建 |
| R07 | 开启整包修订清空三段审批与回听，保留旧包快照 | 原型整包版本；未改的两段也必须重新批准 |
| R08 | 退回→编辑修订→重送→新版本评审完整闭环 | 原型；1轮合并修订商业约束单独记录，不掩盖必要纠错 |
| R09 | 只有当前三段均批准可准备交付清单 | 原型；不能据此标记已交付 |
| R10 | 导出JSON review manifest和明确标记的SRT/txt样例 | 原型；不能冒充MP4成品 |
| R11 | 备份、格式校验、确认替换、恢复后审批关系一致 | 原型；不导入本地媒体二进制 |
| R12 | 可选本地媒体预览；媒体不持久保存、不上传 | 原型；刷新后要求重新选择文件 |
| R13 | 编辑/客户可见操作区分，过期/不合法操作阻断 | 原型演示；非安全边界 |
| R14 | 正式交付需视频、字幕、可编辑稿、章节/文案和验收证据齐备 | 仅生产验收；原型显示未生产边界 |
| R15 | 开工/交期、合并修订和生产前能力/授权/收款核实可追踪 | 正式服务运营；原型不伪造已经核实 |

## 6. 版本规划与退出条件

V0：本地流程原型，验证资料完整性、三个片段审批、版本失效、备份恢复和交付边界；不证明市场或编辑质量。V1：有限人工试单，使用现有剪辑工具制作真实成品并记录端到端工时、语言盲评、修订次数和实际到款；先完成收费前核实。V2：只有复购、质量和贡献成立后再评估托管审稿功能；不预设建设SaaS或AI流水线。

停止条件：语言质量未达标、素材权利/收款无法确认、买家只愿意购买廉价自助工具、返工导致成本不可承受。不能通过降低视频验收标准把试单计为成功。

## 7. 实现与证据边界

静态读取app.js/logic.js确认：最多20期、本地保存、客户端/编辑动作检查、三段时间/内容验证、整包送审与整包修订、逐片决定、manifest与样例下载、2MB备份校验恢复、≤200MB本地视频预览已有代码。代码存在不等于浏览器验收通过，实际结果见检查记录。

原型未覆盖：同一期brief重开/源替换、独立逐片版本、真实素材齐备/交期计算、禁用项必填、语言能力证明、身份认证、视频渲染、逐句字幕制作、实际收款和交付。上述生产条件不得从本地审批推导。
