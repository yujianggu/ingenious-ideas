# Episode Desk 原型使用与检查

[打开原型](index.html) · [设计与评审边界](../05-原型评审记录.md) · [检查记录](../../../../检查记录.md)

直接用桌面浏览器打开index.html，无需安装前端依赖或连接服务。也可从海外市场目录运行 `python3 -m http.server 8767`，再访问本文件所在路径。页面文字为英语，所有示例为虚构内容。

1. 客户勾选素材授权并提交简报。
2. 在页脚展开 Walkthrough tools，切换 View as editor；逐段核对并保存，发送三段审稿。
3. 切换 View as client，逐段批准或填写退回原因。
4. 编辑开启新修订后，三段全部重新核对、发送与批准；旧版本内容和决定保留。
5. 全部批准后，编辑在 Handoff 生成审稿清单；可下载JSON、单条字幕示例和文案。这里不生成实际视频。

简报提交后锁定；更换源素材需新建一期。修订按整包版本处理，不保留未修改片段的批准。浏览器存储保存文字与审稿历史，选择的本地视频只用于当前页面预览，刷新后需重新选择。角色切换是演示工具，不是登录权限。

## 自动检查

需要Node.js。纯状态检查：`node verify-model.cjs`。

浏览器检查需要Playwright与已安装的Google Chrome：`node verify-browser.cjs`。脚本在临时浏览器配置中执行，不操作用户正在使用的浏览器；截图写到系统临时目录。若Playwright安装在共享运行时，需设置该运行时的NODE_PATH。浏览器脚本包含无法解码媒体的拒绝路径，未验证真实素材的播放质量。

交付能力仍以产品需求中的成品视频、准确字幕、人工质检和客户签收为准。此原型只支持设计评审，不能用于处理生产客户资料或实际订单。
