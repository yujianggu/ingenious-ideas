# OS-B04 信息架构与交互规格

版本：1.1｜2026-09-20｜已按app.js/logic.js静态对齐；交互实测见检查记录｜[原型](原型/index.html)｜[需求](../06-产品需求与版本规划/03-产品需求说明书.md)

## 1. 页面结构

英语操作界面以一期episode为工作范围：顶部呈现当前episode、状态和演示角色；侧栏/列表切换历史episode并创建新一期。主体顺序为Brief → Excerpts → Review → Handoff → Activity；备份/恢复为工作区操作。标题栏展示整包版本和阶段；Review的Package status逐段列出决定，不显示独立片段版本。

界面说明本地演示且无真实渲染；Handoff明确“This is not a completed delivery”，预览说明“No video has been rendered”。这些说明用于解释当前原型结果，不能混入未来正式客户购买流程当卖点。

## 2. 客户brief

表单依次展示标题、工作室名、素材总时长、素材引用、品牌词表、品牌/上下文备注和授权确认。素材引用是客户提供的定位文字/URL，原型不自动联网访问。时长旁显示“Up to 60 minutes”。原型允许词表/备注为空，未单列强制禁用声明。正式生产需确认禁用要求，建议无要求写None；不能声称原型已强制校验。

提交成功显示Saved；失败在统一notice显示原因，不清空已填内容。当前没有自动聚焦或逐字段错误展示。同一期brief提交后冻结，不能重开或替换素材；后续生产需建换源重新授权和重审流程。正式生产中“素材齐备”必须由编辑人工验源，不能按创建episode时间自动开工。

## 3. 编辑片段

三个编号卡片各展示开始/结束、计算时长、原话、上下文解释、标题和宣传文案。回听确认置于卡片内容之后，表示针对当前版本；开启整包新修订时三段回听全部清除。编辑阶段保存按用户提交的复选框记录，代码不自动判断是否已真实回听；再次改字应由编辑主动重新核对。可选本地视频只用于本次浏览器会话预览，没有文件时仍可演示文本流程，但不把示例回听勾选当真实验音证据。

Save excerpt即检查该段文本完整和时间有效，不能保存缺字段片段；送审检查三段均已保存并回听，错误在notice中显示。新episode标题/品牌/源引用为空，但三段与章节继承虚构示例，须由编辑替换。标题栏显示整包版本，片段显示当前退回理由；旧送审内容在Activity查看。

## 4. 客户评审

客户阅读每段源区间、原话与上下文，再看标题和文案。Approve批准当前版；Request changes必须填写具体原因。已决定的片段显示决定、版本和时间。尚有待评片段时总状态不能显示全部批准。

客户退回一段后，编辑先Start new revision创建新整包版本，清空三段全部批准和回听；即使只改一段，也须三段重新回听和送审。历史无批准操作，旧版本号提交被拒绝。1轮合并修订指客户把反馈汇总成一次服务修订，不是强制用户为纠错批准不合格内容；超范围修改由正式服务重新确认。

## 5. 准备交付

仅三段当前版全部批准时启用Prepare delivery checklist。清单以“Review handoff”“Sample working files”和“Still needed for production delivery”分区，避免用户把下载manifest或字幕样例理解为已收到成品。

原型可下载review manifest JSON、SRT/txt样例和章节txt；manifest有episodeId及整包version，片段文件名含clip ID和version。样例性质由界面/下载通知说明，单独SRT/txt文件没有完整episodeId或sample文字，不可将孤立文件作为正式交付证明。SRT样例采用片段内时码，源长片开始时间另存在manifest，不混为一谈。正式MP4、完整逐句字幕、可编辑稿、章节和验收记录仍显示待生产。原型没有“已渲染/已发送/已交付”的成功反馈。

## 6. 备份、错误与小屏

备份导出包含所有episode及历史；恢复先解析校验，再展示将替换的范围并让用户确认。取消或失败保留原数据；不能解析一半就覆盖。媒体预览不进入备份。浏览器存储失败应显示提示并允许手动下载备份，不只显示“保存成功”。

现有界面使用label、按钮及文字状态/notice；小屏无遮挡、键盘可达、长文本换行仍需实际浏览器检查，不因静态存在HTML就判通过。编辑未保存变更时阻止切换区块/片段/角色/episode，提供Save或Discard；未提交brief也有离开阻断/丢弃操作；媒体选择与备份导入导出遇未保存表单须先处理。源brief冻结后换源须新建一期。
