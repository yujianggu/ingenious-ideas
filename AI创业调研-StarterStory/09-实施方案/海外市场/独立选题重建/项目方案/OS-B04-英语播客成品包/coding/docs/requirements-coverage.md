# OS-B04 需求到代码映射

此表区分历史V0原型和本次V1产品代码。正式业务尚无真实客户验证，不用测试订单替代商业阶段验收。

| 原需求 | V1实现 |
| --- | --- |
| R01 多episode | SQLite存储、客户所属订单列表、两端多期操作 |
| R02 素材简报与授权 | 服务端必填/类型校验，客户授权，禁用声明，提交后冻结；reopen重新授权 |
| R03/R04 三段与内容核对 | 三固定片段、时间范围、原话/上下文/文案、人工核对；送审前服务器严检 |
| R05/R06 送审与批准 | 整包冻结快照、实名actor、逐片批准/理由退回；服务端鉴权 |
| R07/R08 修订闭环 | 整包version+1、清除全部当前批准、重新核对/送审；旧内容与决定保留 |
| R09 交付关口 | 当前版本全部获批+真实七份文件+技术校验+人工QC后才delivered，客户签收才accepted |
| R10 清单与导出 | JSON审稿清单明确实际状态/缺项、文字稿导出、真实文件下载；原型样例字幕不自动升级为成品 |
| R11 备份恢复 | 服务器SQLite与私有文件一致备份、SHA256核对、恢复到空目录、0700/0600权限；不导入不可信浏览器演示备份到生产 |
| R12 素材预览 | 网页带鉴权读取真实上传视频并预览；移动下载/分享，原生体验待设备复验 |
| R13 身份权限 | 真实编辑注册、一次邀请客户、散列会话、注销撤销、工作室及客户订单隔离；无演示角色切换 |
| R14 正式文件 | MP4解码/音轨/画幅/时长验证、SRT结构和时码验证、可编辑文字/JSON材料、章节、审稿与签收记录 |
| R15 开工交期 | 四项人工开工声明、7自然日到期、额外修订理由；换源清开工时间重新确认。没有自动收费或自动暂停/重排合同交期 |

扩展：所有写操作使用独立revision进行并发控制。网页/手机保存失败保留输入、旧页面409提示显式重载；移动账号切换清除缓存。

成品语义、字幕与声音同步、实际画面/音量质量不能只靠媒体结构校验完成；编辑的QC确认必须来自真实检查。可编辑稿当前约定为可编辑的文字或JSON材料，不能把它宣传成任意视频软件的完整工程文件。
