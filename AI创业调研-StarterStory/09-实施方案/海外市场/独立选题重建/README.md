## 当前方案的具体边界

美国英语、2—5人、服务企业访谈的播客工作室只是首轮招募边界，不是已验证的典型买家。方案交付一期≤60分钟、已完成长片剪辑且获授权的素材，制作3段30—90秒、单一9:16格式短片，配SRT、章节摘要、3条文案和一次合并修改。建议交期为素材齐备及范围确认后7个自然日，不承诺播放量，不包含长片精剪或代运营。

单期$240为测试价假设；首次最多两单。含初始样品模板的两单验证预算为$957.80，其中现金预算含预备金$207.80、人工机会成本$750。若两单均按假设价成交，收入$480，预算差额为−$477.80。不是已支付费用、实收收入或利润保证；详见[资源测算](02-首轮验证与资源安排.md)。

英语专业编辑能力、实际签约收款退款路径、源素材授权均未知，需要在收费前核实。目前没有真实外联、客户访谈、收费、成品验收或复购记录。

原型展示审核流程，导出的manifest是审核清单，不是渲染成品；原型不能转写、剪辑、渲染真实媒体，也不能用流程测试代替成品或市场验收。
