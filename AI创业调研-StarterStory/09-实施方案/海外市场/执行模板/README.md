# 海外执行模板

日期：2026-09-20｜空白模板，未执行。与[国内通用访谈／验收模板](../../国内市场优先/执行模板/README.md)配合使用，海外字段独立登记。

先使用[海外全生命周期模板](全生命周期项目方案模板.md)管理12阶段、R1—R5和六张台账；本页保留国家进入、英文报价、本地化与交付的专项记录。

## A. 创意×国家进入卡

| 字段 | 填写规则 |
| --- | --- |
| 项目／国家／客户类型 | 固定编号；具体国家，不能只写欧洲或英语用户；B2B／B2C分别记 |
| 主体／买家／数据所在地 | 三者分别填写，未确定记未知 |
| 工作语言 | 使用者、付款人、外部接收人分别确认 |
| 近期任务及替代 | 最近发生时间、现有工具版本与结果 |
| 行业审核与语言审核 | 负责人、能力证据、报酬、可投入时间 |
| 允许使用的招募入口 | 许可／规则记录；不能只有一批采集邮箱 |
| 收款路径 | 真实主体、品类、银行结算、币种与账户审核状态 |
| 交易与资料核验 | 最终总价、税处理、退款、资料流和留存；来源与核查日期 |
| 支持窗口 | IANA时区、工作日、假期、响应与修复区别 |
| 本轮预算 | 现金、销售、研发、交付、审校、支持工时分栏 |
| 进入结果 | 可做无收费研究／可做受控付费／暂缓；写明证据 |

## B. 当地访谈与替代对照

先让客户完整讲最近一次任务，后展示产品，不以“你愿意买AI工具吗”替代任务观察。

| 项目 | 计划 | 实际及证据 |
| --- | --- | --- |
| 国家、语言、角色及付款权 | 待填 | 未执行 |
| 原流程各步与总工时 | 待填 | 用户估计和现场测量分开 |
| 失败、返工、求助及后果 | 待填 | 自述注明归属 |
| 现有工具同任务对照 | 待填 | 版本、日期、设备与样本 |
| 新流程学习／迁移／复核工时 | 待填 | 不仅计软件运行时间 |
| 完整报价及拒绝原因 | 待填 | 不是只问大致愿付多少 |
| 第一次／第二次真实任务 | 待填 | 无观察周期则未知 |

不同国家渠道、客群、价格或产品边界不同，要记录混杂因素，不把全部差异归因于国别。

## C. 英文范围与报价骨架

以下是可编辑草稿，不是已批准的合同、广告或发出的消息。方括号待真实订单填写，国家相关条款另核。德国／法国／荷兰按确认语言审校后使用。

> **Project:** [ID and service/product version]
> **Customer task:** [one specific outcome]
> **Included:** [deliverables, quantity, supported language, users and capacity]
> **Customer inputs:** [files, format, authorised use, final input version and approver]
> **Price:** [currency, net base, applicable taxes, final total and payment schedule]
> **Delivery:** [date or business-day window, time zone, input-complete trigger]
> **Acceptance:** [observable checks, reviewer and feedback process]
> **Revisions:** [included scope; corrections to agreed deliverables handled separately]
> **Support:** [service days, time zone and initial response window]
> **Changes:** [new language, platform, document or workflow requires a revised quote]
> **Cancellation and refunds:** [confirmed channel and applicable transaction terms]
> **Data export and retention:** [available formats, access period and deletion process]
> **Confirmation:** [names, date and scope version]

不加入保证录用、保证批准、自动合规或终身免费支持等未经验证承诺。报价单所有数字与实际收款页一致，币种符号不清时写USD／EUR。

## D. 本地化验收单

| 层面 | 要检查什么 | 证据 |
| --- | --- | --- |
| 业务术语 | 确认、退回、待审、可租等状态语义 | 专业审核人逐项确认 |
| 界面与邮件 | 按钮、错误、长文本、遗漏翻译 | 实际设备任务记录 |
| 日期与时区 | 模糊日期、夏令时、截止时间 | 包含真实日期的用例 |
| 金额与数量 | 币种、小数、分隔符、单位与舍入 | 输入到导出往返一致 |
| 文档与文件名 | 重音字符、中文／拉丁字符、分页与字体 | 最终文件可打开可复制 |
| 帮助与售后 | 客户能自主完成，支持语言可兑现 | 无代操作演练 |
| 交易与退出 | 总价、取消、退款、导出和数据保留 | 渠道配置和用户路径核对 |

## E. 收款到交付核对单

记录商户审核状态、商品／服务分类、支付方式、测试交易标识和结果、正式订单号、授权与实际到账差异。使用供应商允许的测试流程；不以沙箱成功宣称真实结算完成。

每笔实际订单登记：客户国家与类型、币种、最终总额、代收税、净收入、渠道费、退款／拒付、结算费、到账日期、交付版本和验收。取消订阅与删除资料是不同动作，要分别记录；退款后是否继续访问按明确条款实施。

## F. 海外交付任务卡

责任人：____；客户验收人：____；专业审核：____；语言审核：____。

输入冻结时间：____；客户业务时区：____；承诺交付时间：____；节假日例外：____。

交付包建议含：输入索引、最终成果、业务口径／术语、验收、变更和售后。真实财务、简历与工程资料进入受控存储，研究仓库只留脱敏结果和证据索引。

严重问题先暂停受影响流程，记录客户、数据、金额或状态影响，告知下一次更新时间，再恢复与复验。不把问题关闭等同客户已经验收。

## G. 周度损益和阶段决策

| 类别 | 预算 | 实际 | 偏差解释 |
| --- | --- | --- | --- |
| 净收入与实际到账 | 待填 | 未发生 | 税、汇率、结算周期分别看 |
| 销售／渠道／转介 | 待填 | 未发生 | 创始人时间也计入 |
| 交付／专业审核／语言审校 | 待填 | 未发生 | 同一工时不重复记 |
| 支持／返工／退款 | 待填 | 未发生 | 预算储备与真实退款不重复扣 |
| 工具／运行／固定开发 | 待填 | 未发生 | 现金与机会成本分栏 |
| 新客／续用／重复任务 | 待填 | 未观察 | 不用意向代替行为 |

决策选择：继续同一组合／只调整一个假设／停止归档／证据不足。写下支持和反对证据、下一阶段工时与现金上限，以及重新开启所需条件。

完成一个国家的完整周期之前，不自动新增第二国开发。海外方案编写、商业执行、提交Git及推送是不同状态，分别记录。
