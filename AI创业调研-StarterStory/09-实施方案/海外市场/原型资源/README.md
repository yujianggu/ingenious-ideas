# 海外产品原型资源

[打开总览](../产品需求与原型总览.html) · [检查记录](../产品需求与原型检查记录.md)

## 运行与维护

10个入口共享 `app.js` 与 `app.css`，各项目HTML内嵌自己的配置，直接以浏览器打开或通过静态HTTP服务访问均可，无打包或外部网络依赖。`products.json`保存配置和用户任务的汇总；修改配置后运行 `node 原型资源/sync-config.cjs` 同步入口，需求文档需同步审查。

从海外市场目录运行 `python3 -m http.server 8767 --bind 127.0.0.1`，然后打开 `http://127.0.0.1:8767/产品需求与原型总览.html`。服务仅监听本机，停止终端进程即停止预览。

## 数据边界

每个项目用独立localStorage键保存浏览器示例记录，支持多条任务。备份JSON只包含原型实际记录；不包含B18附件正文、B17原照片或C18照片。用户可导出结果或备份，选择备份后需确认替换范围。恢复前验证结构、记录标识、结果类型和核心状态关系。原型备份上限2MB；超限导出提示，不提供无法恢复的备份。

C13只读取用户明确选择的文件，限制每侧20个／20MB，以SHA-256筛选后逐字节比较；结果包含双侧独有与未知项。不会上传、删除、移动文件，也不会遍历未选择的目录。

## 交互验证

`verify.cjs`使用Playwright与本机Chrome，覆盖10个项目的主要任务、异常、下载、备份校验及恢复、刷新、多记录和390px窄屏布局。在已提供Playwright的Node环境下运行 `node 原型资源/verify.cjs`；测试结果写到系统临时目录，不放入业务资料。

技术检查不能代替真实认证、跨用户并发、专业审核、平台接入、最终成果文件格式或国家语言验收。各项目需求与原型评审记录分别列出缺项。

恢复格式校验可独立运行 `node 原型资源/verify-validation.cjs`，不依赖浏览器或第三方包。
