| 项目 | 当前设计 |
| --- | --- |
| 客户及角色 | 单国2—5人印刷工作室；设计师使用、店主付款、外部客户确认，店方负责人验收 |
| 价值假设 | 当前版本、有效确认和印前复核形成可追溯闭环 |

| 经营形态与容量 | 网页软件；最多2店、合计10个低风险订单；每店50单／月、2GB |
| 专业能力 | 当地印刷业务负责人＋目标语言审校 |
| 国家与语言 | 美国、德国、法国、荷兰是备选；实际主国家／语言待选择，样本不能合并 |
| 主体、结算、数据流 | 待按实际经营结构核实；客户国家不等于经营主体或服务器所在地 |
| 人员与阶段 | 角色已定义，姓名待指定；阶段均未启动，市场仍M0 |
| 资源基线 | 每周20小时，首两周40小时与外部现金US$200等值为海外原假设；非批准或实际支出 |
| 下一步 | 指定主项目与主国家，填写D01并进入02调研；其余阶段保留计划状态 |
