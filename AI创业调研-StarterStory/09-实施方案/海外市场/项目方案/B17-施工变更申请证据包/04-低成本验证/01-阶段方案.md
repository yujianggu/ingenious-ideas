# B17｜04 低成本验证：阶段方案

版本：海外V2｜状态：设计草案；执行未启动，价格、工时、客户和门槛为计划假设。

## 本阶段任务

8家尝试中3家历史样本，至少1名接收方核规格；先3个脱敏历史包比较整理与查阅时间，无接收格式不开发。试验前登记假设、输入、对照、样本和停止条件；样品只证明被实际观察的任务。先1公司1项目1接收模板；标准包5员工、10项目、100份月申请、2GB为后续受控交付上限，不是当前已获得客户。

## 输入、责任与衔接

主责：产品／交付负责人；验收：项目负责人。姓名、主国家／语言与计划日期待实际启动时登记，内部兼任不能替代客户业务签认。

输入：前序D01—D03中本阶段需要的有效版本及未关闭问题。输出：B17-OS-D04，详见本阶段[产出物与验收](02-产出物与验收.md)。

通过条件：R2的验证输入：实际证据与意向分栏，先达到预登记样品门槛；需要安全版本的真实效果留到09—10后。

## 预登记验证卡

| 项目 | 执行设计 |
| --- | --- |
| 关键假设 | 接收方是否接受以及现场代整理和本地支持能否覆盖 |
| 输入与对照 | 已注明授权的样本或虚构材料；客户当前同任务流程 |
| 样品步骤 | 8家尝试中3家历史样本，至少1名接收方核规格；先3个脱敏历史包比较整理与查阅时间，无接收格式不开发 |
| 早期退出 | 没有重复未满足任务、专业人缺位或样品增加客户总负担 |
| 后续真实指标 | 提交方与接收方共同认可格式、至少1笔真实付款，第二同类项目可复用；每月额外2小时代整理即可能亏损，按完整成本决定是否停；达到所需上线与交易条件后才执行 |
| 证据和预算 | 计划／实际分栏；未付款仍记未验证，预算由R1限定、R2重估 |
