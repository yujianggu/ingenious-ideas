# B17｜施工变更申请证据包：海外项目

版本：V2十二阶段目录版｜2026-09-20｜方案设计，尚未执行。

按接收方格式把变更事项与原附件完整组包并追踪交接。接收方是否接受以及现场代整理和本地支持能否覆盖是首轮重点验证的问题。

## 项目控制卡

| 项目 | 当前设计 |
| --- | --- |
| 客户及角色 | 单国同城市圈专业分包团队；工长录入、办公室审核、负责人付款、总包或业主接收 |
| 价值假设 | 按接收方格式把变更事项与原附件完整组包并追踪交接 |
| 最危险假设 | 接收方是否接受以及现场代整理和本地支持能否覆盖 |
| 经营形态与容量 | 网页软件；先1公司1项目1接收模板；标准包5员工、10项目、100份月申请、2GB |
| 专业能力 | 当地工程伙伴＋接收方格式确认人 |
| 国家与语言 | 美国、德国、法国、荷兰是备选；实际主国家／语言待选择，样本不能合并 |
| 主体、结算、数据流 | 待按实际经营结构核实；客户国家不等于经营主体或服务器所在地 |
| 人员与阶段 | 角色已定义，姓名待指定；阶段均未启动，市场仍M0 |
| 资源基线 | 每周20小时，首两周40小时与外部现金US$200等值为海外原假设；非批准或实际支出 |
| 下一步 | 指定主项目与主国家，填写D01并进入02调研；其余阶段保留计划状态 |
