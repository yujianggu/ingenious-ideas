# C18｜04 低成本验证：阶段方案

版本：海外V2｜状态：设计草案；执行未启动，价格、工时、客户和门槛为计划假设。

## 本阶段任务

5人展示既有工具的真实恢复任务，3人相同缺口才定义差异；先样品与报价，不凭已有竞品付费记录替代本项目付款。试验前登记假设、输入、对照、样本和停止条件；样品只证明被实际观察的任务。首批5人，从10盆开始验证；标准上限100盆、四种事件和一日汇总提醒为后续受控交付上限，不是当前已获得客户。

## 输入、责任与衔接

主责：产品／交付负责人；验收：项目负责人。姓名、主国家／语言与计划日期待实际启动时登记，内部兼任不能替代客户业务签认。

输入：前序D01—D03中本阶段需要的有效版本及未关闭问题。输出：C18-OS-D04，详见本阶段[产出物与验收](02-产出物与验收.md)。

通过条件：R2的验证输入：实际证据与意向分栏，先达到预登记样品门槛；需要安全版本的真实效果留到09—10后。

## 预登记验证卡

| 项目 | 执行设计 |
| --- | --- |
| 关键假设 | 迁移优势是否真实，以及低价售后能否承担提醒和恢复支持 |
| 输入与对照 | 已注明授权的样本或虚构材料；客户当前同任务流程 |
| 样品步骤 | 5人展示既有工具的真实恢复任务，3人相同缺口才定义差异；先样品与报价，不凭已有竞品付费记录替代本项目付款 |
| 早期退出 | 没有重复未满足任务、专业人缺位或样品增加客户总负担 |
| 后续真实指标 | 5人至少4人自主记录与恢复、至少2笔真实付款、至少两周提醒观察；记录迁移／客服工时，不能以植物存活改善证明效果；达到所需上线与交易条件后才执行 |
| 证据和预算 | 计划／实际分栏；未付款仍记未验证，预算由R1限定、R2重估 |
