# B12｜04 低成本验证：阶段方案

版本：海外V2｜状态：设计草案；执行未启动，价格、工时、客户和门槛为计划假设。

## 本阶段任务

5家中2家各给20次历史流转；脱敏回放延期、损坏与后续冲突，比原系统操作；真实库存只在规则验收后导入。试验前登记假设、输入、对照、样本和停止条件；样品只证明被实际观察的任务。最多2仓库客户，各先50件序列号设备；标准包10员工、500件、月200次流转、2GB为后续受控交付上限，不是当前已获得客户。

## 输入、责任与衔接

主责：产品／交付负责人；验收：项目负责人。姓名、主国家／语言与计划日期待实际启动时登记，内部兼任不能替代客户业务签认。

输入：前序D01—D03中本阶段需要的有效版本及未关闭问题。输出：B12-OS-D04，详见本阶段[产出物与验收](02-产出物与验收.md)。

通过条件：R2的验证输入：实际证据与意向分栏，先达到预登记样品门槛；需要安全版本的真实效果留到09—10后。

## 预登记验证卡

| 项目 | 执行设计 |
| --- | --- |
| 关键假设 | 现场员工是否持续更新及中国时区团队能否覆盖真实支持需求 |
| 输入与对照 | 已注明授权的样本或虚构材料；客户当前同任务流程 |
| 样品步骤 | 5家中2家各给20次历史流转；脱敏回放延期、损坏与后续冲突，比原系统操作；真实库存只在规则验收后导入 |
| 早期退出 | 没有重复未满足任务、专业人缺位或样品增加客户总负担 |
| 后续真实指标 | 零重复分配、至少90%当天登记、至少1家真实付款；每日创始人代录超过20分钟就停止软件扩量，支持超预算单列重估；达到所需上线与交易条件后才执行 |
| 证据和预算 | 计划／实际分栏；未付款仍记未验证，预算由R1限定、R2重估 |
