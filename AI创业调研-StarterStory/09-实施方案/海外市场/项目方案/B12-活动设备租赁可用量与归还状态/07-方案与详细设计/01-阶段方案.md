# B12｜07 方案与详细设计：阶段方案

版本：海外V2｜状态：设计草案；执行未启动，价格、工时、客户和门槛为计划假设。

## 本阶段任务

序列号与数量件分开；可租交集包括就绪、时间占用和缓冲；并发约束、重复扫码幂等、弱网未提交显示和带时区日志。将目标语言、单位、日期格式、IANA时区、人工审核、错误提示、资料留存与恢复责任写入设计；与D06逐条对应，不引入未经访谈的全平台需求。

## 输入、责任与衔接

主责：技术／交付负责人；验收：产品负责人及专业审核人。姓名、主国家／语言与计划日期待实际启动时登记，内部兼任不能替代客户业务签认。

输入：前序D01—D06中本阶段需要的有效版本及未关闭问题。输出：B12-OS-D07，详见本阶段[产出物与验收](02-产出物与验收.md)。

通过条件：R3：D06—D07的规则、权限、生产和恢复设计可验证；关键风险有样品证据，重估排期成本后再实施。

## 设计记录与故障路径

| 设计项 | 本项目要明确的内容 |
| --- | --- |
| 核心规则 | 序列号与数量件分开；可租交集包括就绪、时间占用和缓冲；并发约束、重复扫码幂等、弱网未提交显示和带时区日志 |
| 使用与审核 | 单国单仓50—500件活动设备租赁商；仓管配送使用、店主付款与库存基线验收；由当地仓管与现场支持伙伴确认业务含义 |
| 语言与格式 | 只实现已选择的语言；保留特殊字符，日期、币种、单位与时区显式，原国别差异参照02 |
| 错误与恢复 | 导入50件预览，由客户盘点确认基线；3个约定工作日完成配置培训；错配停新分配、保留事件，回人工调度核对后恢复 |
| 追溯 | 需求ID→设计记录→实现版本→TC用例→实际证据 |

所选技术、服务商、数据保留期及负责人仍须在真实立项后定稿；不得将架构占位或SOP草案写成已部署实现。
