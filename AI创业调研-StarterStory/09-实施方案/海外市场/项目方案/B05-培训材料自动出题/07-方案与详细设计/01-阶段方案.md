# B05｜07 方案与详细设计：阶段方案

版本：海外V2｜状态：设计草案；执行未启动，价格、工时、客户和门槛为计划假设。

## 本阶段任务

教材版本与题号绑定，记录知识点、出处、答案、解析及审题状态；草稿不可直接交付；专业正确性和语言歧义分别检查。将目标语言、单位、日期格式、IANA时区、人工审核、错误提示、资料留存与恢复责任写入设计；与D06逐条对应，不引入未经访谈的全平台需求。

## 输入、责任与衔接

主责：技术／交付负责人；验收：产品负责人及专业审核人。姓名、主国家／语言与计划日期待实际启动时登记，内部兼任不能替代客户业务签认。

输入：前序D01—D06中本阶段需要的有效版本及未关闭问题。输出：B05-OS-D07，详见本阶段[产出物与验收](02-产出物与验收.md)。

通过条件：R3：D06—D07的规则、权限、生产和恢复设计可验证；关键风险有样品证据，重估排期成本后再实施。

## 设计记录与故障路径

| 设计项 | 本项目要明确的内容 |
| --- | --- |
| 核心规则 | 教材版本与题号绑定，记录知识点、出处、答案、解析及审题状态；草稿不可直接交付；专业正确性和语言歧义分别检查 |
| 使用与审核 | 单国单语言咖啡连锁新人培训；培训人员使用，运营或人力付款，指定业务专家审题验收；由教材业务专家＋目标语言审题人确认业务含义 |
| 语言与格式 | 只实现已选择的语言；保留特殊字符，日期、币种、单位与时区显式，原国别差异参照02 |
| 错误与恢复 | 用目标考试系统或客户认可的导入样本演练字段和编码，固定教材版本后5个约定工作日给初版；错误题包停用并发布更正版，接收人确认替换 |
| 追溯 | 需求ID→设计记录→实现版本→TC用例→实际证据 |

所选技术、服务商、数据保留期及负责人仍须在真实立项后定稿；不得将架构占位或SOP草案写成已部署实现。
