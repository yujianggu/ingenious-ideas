## 项目控制卡

| 项目 | 当前设计 |
| --- | --- |
| 客户及角色 | 单国一个目标岗位、1—3年经验且30天内求职的人；本人付款和事实确认，当地岗位顾问审核 |
| 价值假设 | 真实经历经专业追问后形成可直接使用的单岗位文档包 |
| 最危险假设 | 当地顾问是否超过成熟自助工具，全部访谈与修订时间能否覆盖 |
| 经营形态与容量 | 专业服务；首批至少2单、每周最多3单；母版＋一个岗位版＋一次范围内修订 |
| 专业能力 | 熟悉目标国家和岗位的招聘顾问＋目标语言审核 |
| 国家与语言 | 美国、德国、法国、荷兰是备选；实际主国家／语言待选择，样本不能合并 |
| 主体、结算、数据流 | 待按实际经营结构核实；客户国家不等于经营主体或服务器所在地 |
| 人员与阶段 | 角色已定义，姓名待指定；阶段均未启动，市场仍M0 |
| 资源基线 | 每周20小时，首两周40小时与外部现金US$200等值为海外原假设；非批准或实际支出 |
| 下一步 | 指定主项目与主国家，填写D01并进入02调研；其余阶段保留计划状态 |
