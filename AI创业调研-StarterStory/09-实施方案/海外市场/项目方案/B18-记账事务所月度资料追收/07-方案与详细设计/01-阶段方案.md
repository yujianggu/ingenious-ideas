# B18｜07 方案与详细设计：阶段方案

版本：海外V2｜状态：设计草案；执行未启动，价格、工时、客户和门槛为计划假设。

## 本阶段任务

机构／客户／期间隔离；上传与通过分离，必需项通过才齐套；链接过期撤销、下载权限、提醒去重；按实际主体和远程访问画资料流。将目标语言、单位、日期格式、IANA时区、人工审核、错误提示、资料留存与恢复责任写入设计；与D06逐条对应，不引入未经访谈的全平台需求。

## 输入、责任与衔接

主责：技术／交付负责人；验收：产品负责人及专业审核人。姓名、主国家／语言与计划日期待实际启动时登记，内部兼任不能替代客户业务签认。

输入：前序D01—D06中本阶段需要的有效版本及未关闭问题。输出：B18-OS-D07，详见本阶段[产出物与验收](02-产出物与验收.md)。

通过条件：R3：D06—D07的规则、权限、生产和恢复设计可验证；关键风险有样品证据，重估排期成本后再实施。

## 设计记录与故障路径

| 设计项 | 本项目要明确的内容 |
| --- | --- |
| 核心规则 | 机构／客户／期间隔离；上传与通过分离，必需项通过才齐套；链接过期撤销、下载权限、提醒去重；按实际主体和远程访问画资料流 |
| 使用与审核 | 单国小型记账机构；记账员审资料，负责人付款，外部客户上传；专业人定义清单；由当地记账专业负责人＋资料权限／数据流负责人确认业务含义 |
| 语言与格式 | 只实现已选择的语言；保留特殊字符，日期、币种、单位与时区显式，原国别差异参照02 |
| 错误与恢复 | 专业人签认模板后2个约定工作日开3客户试点；演练授权撤销、导出恢复、在线和备份留存；错配或误发停门户相关入口并核影响 |
| 追溯 | 需求ID→设计记录→实现版本→TC用例→实际证据 |

所选技术、服务商、数据保留期及负责人仍须在真实立项后定稿；不得将架构占位或SOP草案写成已部署实现。
