# B10｜业务表格与报表助手

版本：V4阶段目录版｜2026-09-20｜状态：方案设计，尚未执行。

把每周三张来源表变成一份可以复算的经营周报。先卖稳定口径和异常核对，首单就暴露输入变化成本，避免接入费掩盖持续交付亏损。

## 项目控制卡

| 项目 | 当前口径 |
| --- | --- |
| 目标客户与角色 | 同一平台、2—5店的小型电商团队；运营负责人使用、店主付款、指定人员确认金额口径 |
| 核心价值假设 | 将订单、退款、广告三表变成可复算的周报，减少整理和核对总时间 |
| 首批交付规模 | 首家付费接入，初期最多2家 |
| 商业及投入基线 | 接入3000元＋1500元／月含4次周报；月贡献680元、首月月包扣获客后80元为原假设；接入收入单独核算 |
| 专业能力依赖 | 客户运营口径负责人及金额复核人 |
| 发起人／项目负责人／运营接收人 | 角色已定义，姓名待实际启动时指定 |
| 时间与预算 | 沿用每周20小时、首两周不超过40小时及外部现金500元的默认规划；项目更低样品上限优先。均未经实际批准 |
| 当前下一步 | 指定负责人，填写D01，进入02商业与市场调研目录启动真实调研；其余阶段为计划，不预先标为通过 |
