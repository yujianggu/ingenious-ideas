# B10｜试点排期与经营复盘

> V3阶段导航：见[全生命周期主计划](00-全生命周期主计划.md)。本文件保留商业参数或执行细则；阶段顺序、产出物与评审按主计划执行，原数字仍为待验证假设。

版本：V2｜时间从本项目正式选定启动计算，以下为计划而非进度报告。

## 1. 分阶段执行

- 第1周：收集3套同平台脱敏样本、拆解旧周报流程。
- 第2周：形成输入字典、退款口径和1份历史样报。
- 第3周：签明接入范围，完成历史一期对账验收。
- 第4—7周：连续交付4次周报，逐次登记变更与核对用时。
- 第8周：复盘月包贡献和续用。
- 第9—12周：接第二家同类客户，统计新增映射工作占比。

经营负责人承担招募、报价、预算与阶段决策；交付负责人完成样品、质量与支持；客户确认业务输入和验收；需要岗位、培训或业务专业判断时由对应审核人承担，缺人不默认由AI补位。一人兼任时仍分别记工时。每个阶段未取得所需证据就保留“证据不足”，日期到了不自动放行。

## 2. 关键指标怎么记

每周交付总工时=收件沟通+清洗+核对+解释+客户反馈修订；客户耗时也单列。关键金额差异必须在约定精度内为0或有双方认可的口径桥接；未解释差异数不能被平均值掩盖。连续4次是观察窗口，月包预算3小时复核仅为部分成本，超出的沟通不得漏记。

| 记录 | 计划值来源 | 实际值 | 证据 |
| --- | --- | --- | --- |
| 合格样本与完整报价数 | 原实施方案及本次分阶段任务 | 未执行 | 客户代号、日期、范围版本 |
| 自主完成与失败任务 | 本项目场景验收及业务门槛 | 未执行 | 任务ID、帮助次数、失败原因 |
| 客户原流程与新流程时间 | 同任务现场观察优先 | 未执行 | 步骤计时、回忆估计注明 |
| 付款、验收与重复使用 | 各节点分别计，不互相代替 | 未执行 | 真实凭据、成果、后续任务 |
| 销售、研发、交付、支持时间 | 各类分开记录 | 未发生 | 日期、任务、小时和归属 |
| 成本、退款及返工 | 统一成本口径 | 未发生 | 支出凭据、返工单 |

## 3. 首次交付包与上线动作

接入交付：三表模板、字段字典、历史样报、差异桥和口径签认记录；每周交付：本期工作簿、输入索引、异常清单、与上版差异；月末交付：4次验收汇总及真实工时。接入验收和周报验收独立，缺失本期输入时发缺项单并重排。

交付前对照报价确认数量和格式，负责人先完成内部验收。现场观察客户从输入到取得结果的完整路径；把口头提示和代操作记下来。结束时请客户明确通过或列出问题，不把沉默或登录次数当验收。

## 4. 经营边界与调整

若样报正确但客户仍需重做全套报表，查口径和使用环节是否错位；第二客户需要重写大部分规则时保留定制服务定位；若每周多1小时，按原成本表月贡献降至80元，先约束输入或重报价。不得靠多接客户解决单客交付失控。

沿用[统一成本表](../../01-成本与经营测算.md)的基线，实际经营需替换假设：收入按约定周期登记，到账与收入分开；创始人工时属于经济成本；一次性研发与持续维护分开。退款准备和实际退款在同一测算里不得重复扣。前期研究、试用、差旅或实施费用未包含时单列，不暗中挪入低额支持预算。

## 5. 每周复盘议程

1. 看本周真实任务：谁尝试、谁完成、失败在哪一步；先看反证再看成功截图。
2. 对照客户和服务方总用时，定位省下的时间是否被配置、审核或支持抵消。
3. 核实际付款与退款、全部工时和现金支出，不能用预算数填实际。
4. 从客户范围、输入、流程、价格、渠道中选一个主要变量调整，记录原因和新版口径。
5. 明确下周只做的任务、责任人、截止日和预算；达不到继续条件就暂停扩张。

## 6. 阶段决定记录

| 字段 | 当前状态／填写内容 |
| --- | --- |
| 负责人、起止日期、预算 | 待正式启动时指定 |
| 最危险假设 | 使用本项目目录的核心验证问题 |
| 支持证据 | 尚未取得，不能填模拟演示 |
| 反对证据和拒绝原因 | 尚未观察，后续完整保留 |
| 结论 | 未执行；执行后选继续／调整／停止／证据不足 |
| 下一阶段投入 | 在证据复盘后确定，不自动释放全研发预算 |
| 重启条件 | 若停止，写明需要出现哪种新证据 |
