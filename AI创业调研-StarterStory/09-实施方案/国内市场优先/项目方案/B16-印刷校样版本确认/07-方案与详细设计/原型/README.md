# 印刷校样版本确认｜用户任务交互原型

[打开原型](index.html)。直接用浏览器打开即可。脚本、样式和验证脚本均在当前原型目录；复制整个 idea 目录即可独立使用。

## 怎么体验

建立订单与校样 → 发送确认 → 客户查看并确认或退回 → 店员修改重发 → 当前版确认后印前复核 → 留存记录。

先在当前入口填写资料并操作；需要体验另一个角色时，展开底部“原型工具与评审说明”切换。角色共用同一个示例任务，因此前一角色的提交和退回会影响后一角色。工具区可重置示例。

## 当前能做什么

可编辑文字校样、客户确认/退回、重新发版、印前复核、版本记录、JSON确认摘要。文字校样用于体验，未实现真实PDF/图片上传、确认链接发送、身份核验或文件摘要校验。

仅使用虚构数据，浏览器会话内保存输入和进展，无外部发送。下载是原型示例结果，不作为正式成果。刷新可继续，关闭会话不保证保留；个人工具可导出示例备份再恢复。

## V3继续使用

在“我的订单”中新建第二条，填写不同内容；回到第一条检查原来的输入和状态。新建第二个订单后回到第一个，原版本、客户意见和确认状态不变；客户入口不列出其他订单。

需要修改原始资料时使用明确的修改入口；不要用重置替代修订。重置仅作用于当前记录。植物和绣线的下载备份覆盖整个列表；恢复前可取消，旧版单条备份仅替换当前记录。

## 本项目维护与验证

`app.js`和`app.css`为本原型自带资源，不依赖外层目录。安装Node.js、Playwright与Chrome后，在本目录运行 `node verify.cjs` 和 `node verify-workspaces.cjs`；测试仅验证本 idea。可通过NODE_PATH指定已有Playwright安装位置。
