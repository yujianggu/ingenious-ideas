# C18｜盆栽养护历史与检查提醒

版本：V4阶段目录版｜2026-09-20｜状态：方案设计，尚未执行。

围绕可靠保留与恢复养护历史，而非给植物开处方。必须先证明已有工具之外的迁移理由，再设计照片与提醒的细节。

## 项目控制卡

| 项目 | 当前口径 |
| --- | --- |
| 目标客户与角色 | 30—100盆且已有记录习惯、面临换机或历史资料问题的国内个人；本人使用并付款 |
| 核心价值假设 | 可靠保留和恢复养护历史，提供用户自定检查提醒 |
| 首批交付规模 | 5名用户从10盆起步，至少两周真实检查观察 |
| 商业及投入基线 | 59元当前大版本买断、12个月兼容支持；研发45小时＋工具200元、首年维护合计5600元；单笔贡献28.20元为假设 |
| 专业能力依赖 | 备份恢复与设备兼容验收负责人，用户确认历史完整 |
| 发起人／项目负责人／运营接收人 | 角色已定义，姓名待实际启动时指定 |
| 时间与预算 | 沿用每周20小时、首两周不超过40小时及外部现金500元的默认规划；项目更低样品上限优先。均未经实际批准 |
| 当前下一步 | 指定负责人，填写D01，进入02商业与市场调研目录启动真实调研；其余阶段为计划，不预先标为通过 |
