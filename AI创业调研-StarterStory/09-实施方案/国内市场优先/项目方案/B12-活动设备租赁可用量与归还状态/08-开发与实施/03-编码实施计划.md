**HTTP错误实现契约：** 使用自定义`ApiSessionAuthentication(SessionAuthentication)`，`authenticate_header(request)`返回`Session`，未认证映射401；CSRF失败和已认证越权仍403。`config.exceptions.api_exception_handler`将DRF ValidationError统一转422，将业务Conflict转409，错误结构固定code/message/current_revision；其他框架认证权限异常保持401／403。文件quarantined／rejected不返回内容，409只返回状态及失败原因。下列核心片段属于Task 1明确实现内容：

```python
from rest_framework.authentication import SessionAuthentication
from rest_framework.exceptions import ValidationError
from rest_framework.views import exception_handler

class ApiSessionAuthentication(SessionAuthentication):
    def authenticate_header(self, request):
        return 'Session'

def api_exception_handler(exc, context):
    response = exception_handler(exc, context)
    if response is not None and isinstance(exc, ValidationError):
        response.status_code = 422
    return response
```

补统一错误body和Conflict映射时逐断言测试，不吞500为“成功”；JSONRenderer保持默认即可，`REST_FRAMEWORK`显式指定认证类及exception handler。新增`tests/test_http_contract.py`分别断言匿名401、CSRF403、字段422及修订409。
