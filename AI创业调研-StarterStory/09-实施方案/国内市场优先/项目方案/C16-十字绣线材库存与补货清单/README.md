# C16｜十字绣线材库存与补货清单

版本：V4阶段目录版｜2026-09-20｜状态：方案设计，尚未执行。

验证一次备线到下一次备线之间，用户是否愿意持续维护库存。价值不能只算购物单生成的几秒，必须把首次录入与采购后的更新一起算进去。

## 项目控制卡

| 项目 | 当前口径 |
| --- | --- |
| 目标客户与角色 | 100种以上绣线、有近期备线与采购任务的个人爱好者；本人使用并付款 |
| 核心价值假设 | 生成可信的缺线与待核清单，减少重复购买和二次备线负担 |

| 专业能力依赖 | 真实绣线使用者及库存规则验收负责人 |
| 发起人／项目负责人／运营接收人 | 角色已定义，姓名待实际启动时指定 |
| 时间与预算 | 沿用每周20小时、首两周不超过40小时及外部现金500元的默认规划；项目更低样品上限优先。均未经实际批准 |
