# C16｜08 开发与实施：阶段方案

版本：V5｜状态：技术路线已采用、实施未启动。既有商业价格不变，工时估算与新增预算仍需按实际投入核定。

## 本阶段任务

先做库存和缺量规则，再做采购耗用事件、导入撤销与离线备份恢复；用20色示例验证完整任务。保留版本、配置或模板、运行说明、问题台账与交付清单。

## 按采用基线实施

采用 **Android 首发，Flutter + Dart + sqflite/SQLite**。按以下顺序产生实际开发成果；本轮只调整文档，不把条目预填为已完成。

1. 建立 Android 首发 Flutter 工程、纯 Dart 半束规则模块和 sqflite 数据层，固定工具链；20 色首用样本确认色号字符串与待核输入。
2. 实现单品牌/一个活动项目、多色号库存、revision 清单失效、幂等入库/耗用与受约束撤销；事务同时维护余额和流水。
3. 实现 CSV 整批预览、校验与提交；一致性 JSON 导出通过 SAF 创建新文件，不覆盖旧 URI；恢复临时库验证、预览 revision 与回滚。
4. Android 真机断网、强杀、写满、权限取消、干净安装恢复验证；完成签名 APK、依赖许可清单与选定渠道安装更新。

执行前登记负责人、最低系统/依赖版本、测试设备与样本；预算沿用技术方案的估算区间，但须分别记录获批额度与实际投入，40小时/500元验证情境不是完整正式实现预算。
