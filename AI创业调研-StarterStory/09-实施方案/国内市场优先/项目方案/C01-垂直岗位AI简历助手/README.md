# C01｜垂直岗位AI简历助手

版本：V4阶段目录版｜2026-09-20｜状态：方案设计，尚未执行。

让一个细分岗位的经历能够被本人解释、被顾问核实、被招聘方读懂。把AI表达能力与岗位判断分开计成本，先验证299元单岗位包的专业增量。

## 项目控制卡

| 项目 | 当前口径 |
| --- | --- |
| 目标客户与角色 | 1—3年经验、30天内换工作的跨境电商运营人员；本人付款和核实事实，岗位顾问专业审核 |
| 核心价值假设 | 形成事实可追溯、针对一个岗位的可用简历，减少用户修改时间 |
| 首批交付规模 | 至少2笔299元真实订单，首批每周最多3单 |
| 商业及投入基线 | 299元含15分钟访谈、经历母版、一个目标岗位版、说明和一次范围内修订；获客后贡献126.34元为基线，若访谈另计则106.34元 |
| 专业能力依赖 | 合格跨境电商岗位顾问及求职者本人 |
| 发起人／项目负责人／运营接收人 | 角色已定义，姓名待实际启动时指定 |
| 时间与预算 | 沿用每周20小时、首两周不超过40小时及外部现金500元的默认规划；项目更低样品上限优先。均未经实际批准 |
| 当前下一步 | 指定负责人，填写D01，进入02商业与市场调研目录启动真实调研；其余阶段为计划，不预先标为通过 |
