## V3推进方式

先读主计划，再按阶段查01—04细则。正式立项、需求设计、测试、上线交接、上市和收益复盘均须留存实际证据；现有文件是设计依据，不代表阶段已验收。实际执行使用[全生命周期模板与台账](../../执行模板/全生命周期项目方案模板.md)。

## 本轮开始前

先指定负责人、可投入工时、客户入口和现金上限，完成第二份文件的旧流程观察，再决定是否进入原型或付费试点。排期按本项目独立启动计时，十项不是同时开工承诺。首两周默认总投入不超过40小时、外部现金500元；项目更低上限优先，研发计入原预算，销售与额外研究单列。

所有新增业务情节均为虚构演示设计；价格、样本量、时限和门槛均为待验证假设。此轮不新增竞品事实或法律结论，已有证据见[依据与口径](../../02-依据与口径变更.md)。
