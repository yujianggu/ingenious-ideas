# B18｜记账事务所月度资料追收

版本：V4阶段目录版｜2026-09-20｜状态：方案设计，尚未执行。

把月度缺项追收整理成“客户—期间—资料项”的明确状态。先验证客户愿意上传，以及减少催问是否真的降低总工作量。

## 项目控制卡

| 项目 | 当前口径 |
| --- | --- |
| 目标客户与角色 | 20—50客户、2—5员工的国内代账机构；记账员使用、机构负责人付款、外部客户上传 |
| 核心价值假设 | 按客户和期间识别缺项，减少催问且不增加配置与审核总工作量 |
| 首批交付规模 | 2家机构各3名自愿客户，真实资料接入前先完成隔离验收 |
| 商业及投入基线 | 299元／月、30客户3员工5GB；研发经济成本8800元、月贡献170.05元为原假设；代配置和催问单列成本 |
| 专业能力依赖 | 客户方清单专业人员与机构负责人 |
| 发起人／项目负责人／运营接收人 | 角色已定义，姓名待实际启动时指定 |
| 时间与预算 | 沿用每周20小时、首两周不超过40小时及外部现金500元的默认规划；项目更低样品上限优先。均未经实际批准 |
| 当前下一步 | 指定负责人，填写D01，进入02商业与市场调研目录启动真实调研；其余阶段为计划，不预先标为通过 |
