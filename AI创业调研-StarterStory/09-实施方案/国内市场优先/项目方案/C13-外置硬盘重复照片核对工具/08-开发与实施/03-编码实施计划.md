> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付可安装的 macOS App，让用户对最多 4 盘 10 万普通文件完成只读扫描、证据分组、重连复核与报告留存。

**Architecture:** SwiftUI 负责任务/范围/进度/证据界面，Swift actor 控制有界读取和 SQLite 写事务。Foundation 负责目录授权、卷与文件身份，CryptoKit 负责完整摘要；字节复核单独记证据。数据库及输出与源目录隔离。

**Tech Stack:** macOS、SwiftUI、Swift Concurrency、Foundation、CryptoKit、系统 SQLite、XCTest/XCUITest、Xcode。

## Global Constraints

- “macOS普通文件目录、最多4盘10万文件”；“源文件只读”；“没有删除、移动或自动清理”。
- “不扫描未授权目录；同名盘不视为同一盘”；“证据不足不升级为内容一致；历史索引带时间”。
- macOS 首发已采用；最低系统以 macOS 13 起测并由 Xcode/SDK 与目标真机确认，不承诺 Windows。
- 每盘默认 1 个读取流、全局最多 2 个，块大小 4 MiB 起测；不是未实测性能承诺。
- App 放 `coding/app`（桌面客户端也是 app）；不创建没有职责的 backend/frontend，不退回 HTML 产品。
- 原价格、4盘10万边界不变；120–184小时估算未自动成为已批预算。

## Review Focus

- 克隆卷与同名卷：身份不确定不能继承旧证据，Task 2 用卷身份冲突测试固定。

```swift
import SQLite3
struct ScanTask: Identifiable, Codable { let id: UUID; var name: String }
enum StoreError: Error { case sqlite(Int32) }
// TaskStore owns private var db: OpaquePointer? and closes it in deinit.
func insertTask(db: OpaquePointer?, id: UUID, name: String) throws {
    var statement: OpaquePointer?
    let sql = "INSERT INTO task(id,name) VALUES(?,?)"
    var code = sqlite3_prepare_v2(db, sql, -1, &statement, nil)
    guard code == SQLITE_OK else { throw StoreError.sqlite(code) }
    defer { sqlite3_finalize(statement) }
    let copyText = unsafeBitCast(-1, to: sqlite3_destructor_type.self)
    code = sqlite3_bind_text(statement, 1, id.uuidString, -1, copyText)
    guard code == SQLITE_OK else { throw StoreError.sqlite(code) }
    code = sqlite3_bind_text(statement, 2, name, -1, copyText)
    guard code == SQLITE_OK else { throw StoreError.sqlite(code) }
    code = sqlite3_step(statement)
    guard code == SQLITE_DONE else { throw StoreError.sqlite(code) }
}
```

        app.launch()

}
