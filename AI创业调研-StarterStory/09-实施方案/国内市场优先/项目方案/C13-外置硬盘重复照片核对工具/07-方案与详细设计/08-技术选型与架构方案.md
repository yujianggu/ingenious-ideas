# C13｜技术选型与架构方案

采用基线 V2｜2026-09-20｜用户已确认按推荐方案推进；技术路线已采用，产品实现与真实验收尚未启动，新增工时和现金预算未自动获批。

## 已采用决策与执行条件

采用 **macOS 原生 SwiftUI + Swift Concurrency + Foundation 文件访问 + CryptoKit SHA-256 + 系统 SQLite**。首版保留现有 PRD 的国内 Mac 用户、普通目录、最多 4 盘 10 万文件口径；不改为 Windows 首发。数据库、日志、报告写入本机应用目录或另选输出目录，源盘只读。无需服务器、账户、模型 API 或云存储。

原生方案直接处理目录授权、磁盘身份和掉盘事件，减少只服务 Mac 时的桥接层。执行需配备能调试 macOS 文件系统的 Swift 开发者；人员能力差距通过排期、培训或协作补齐，不因此自动重新选栈。

| 备选 | 适用条件 | 本轮取舍 |
| --- | --- | --- |
| Tauri 2 + TypeScript + Rust + SQLite | Windows 和 Mac 同时获得足够付费验证，团队熟悉 Rust | 可复用扫描核心，但仍需两套磁盘身份、授权、安装测试；本轮不增加第二平台 |
| Electron + Node.js | 既有成熟 Electron 团队、桌面交付经验可复用 | 能实现本地读取；当前没有足以抵消额外运行时与打包成本的条件 |
| 浏览器/PWA、微信小程序 | 演示报告或轻量查看 | 不承担本项目多盘身份、长期扫描、中断恢复的主产品职责；保留现有 HTML 仅用于交互评审 |

备选仅供新市场证据、实测不可接受障碍或明确的平台范围变更时重新评估；需记录影响与决定，不是本轮仍可任意切换的路线。最低系统、依赖版本及设备矩阵仍须实测冻结。

## 用户任务与模块

| 需求 | 实现模块与交付规则 |
| --- | --- |
| R01 范围、R06 多任务 | 系统目录选择器；任务与授权目录独立保存；显示实际路径和盘身份，不用盘名当主键 |
| R02 扫描、A04/A06/A09 异常 | 分块读取队列、逐文件检查点、取消令牌；已完成、失败、未处理数量分别显示 |
| R03 证据等级 | 大小筛选→全文件 SHA-256→同时在线的候选逐字节比较；哈希匹配与内容一致分别记证据 |
| R04 重连 | 卷身份重新验证、授权重新取得；只重试选定失败项，不把旧摘要当新扫描结果 |
| R05 报告、R07 历史 | JSON 与可阅读 HTML 报告；包含算法、时间、覆盖范围与失败原因；不同任务证据不可串用 |

## 架构与数据流

`SwiftUI → 任务命令 → 授权/磁盘适配器 → 有界扫描队列 → SQLite 事务 → 证据查询/报告导出`。

扫描工作移出主线程；每盘默认 1 个顺序读取流、全局最多 2 个读取流，作为待实测初值，避免外置机械盘因无界并发反复寻道。分块 4 MiB 起测，完成一个文件才提交完整摘要；取消或断电产生的半个摘要不会进入匹配组。大小仅用于筛候选，不构成副本证据；空文件单独标识。默认不跟随符号链接、不进入照片图库包、不遍历授权范围外路径。

| 表/对象 | 关键字段与不变量 |
| --- | --- |
| volume | 内部 UUID、系统卷 UUID（可空）、文件系统类型、用户别名、身份置信状态；系统标识缺失或克隆冲突时要求重新识别 |
| scan_task / scan_root | 任务 UUID、所选卷/目录、授权书签、规则版本、覆盖计数、状态；书签只是访问凭证，不是盘身份 |
| file_observation | 批次、卷、相对路径、可用的文件资源标识、大小、修改时间、读前/后属性、摘要及算法、错误码 |
| comparison | 两个 observation ID、证据类型、比较时间、实际比较字节数；历史证据不可直接变成本轮有效证据 |
| checkpoint / report | 已完成文件游标、待试条目、应用版本、导出时间；报告中同时保留历史检查时间与当前在线状态 |

卷 UUID 是一项证据而非绝对物理身份：克隆盘可能有相同标识，缺失时也不能退化为盘名匹配。识别组合包括系统标识、文件系统与所选目录；遇到冲突、标识缺失或根目录变化，进入“需要重新识别”，新建卷记录并重新扫描，不静默沿用旧索引。不向源盘写应用识别文件。跨任务只复用候选索引，最终证据重新读取。

每次读取前后检查文件身份、大小、修改时间；检测到变化则重扫或未知。普通目录读取不是文件系统原子快照，无法证明整个目录在同一时刻一致；界面明确要求核对期间暂停其他写入。即使属性没变，后续复核也读取实际内容，报告表达“该次读取所得证据”，不宣称永远存在有效副本。

## 权限、故障和备份

- 源文件仅以只读方式打开；源访问模块不暴露写入、删除、移动或改名命令。导出路径规范化后必须在扫描根外，数据库只在应用数据目录。系统可能因读取维护访问时间，验收区分应用主动写入与系统元数据行为，不许承诺连系统行为也绝对不变。
- 目录授权撤销、书签失效、权限拒绝分别显示；只申请所选目录访问，不将全盘访问作为默认解决办法。程序重启后先重新解析授权和身份，再继续队列。
- 拔盘或休眠：保留完整提交的记录；受影响文件未知，待重新连接后从文件边界重新读，不续接不可信的半段哈希。队列停止新增但界面可取消。
- 数据库写满或事务失败：停止产生成功证据，保留最后已提交批次，恢复空间后重试。超 4 盘/10 万文件停止新增，并给出已覆盖范围。
- 备份使用 SQLite online backup 生成一致快照和 manifest，不直接复制运行中的 `.db`；恢复到临时库，检查 schema、完整性、外键、任务数量与摘要后再切换。历史索引恢复不恢复当前访问授权，也不表示磁盘仍在线。报告不是照片备份。

## 构建、分发与依赖

用 Xcode 固定工具链与最低系统版本；暂定 macOS 13 起测，最终以 5 位试用者设备和所选 SDK 支持范围冻结。Apple Silicon 为必测；若支持 Intel 则增加对应真机/产物验证，不能仅凭编译成功承诺兼容。采用 Developer ID 签名、公证并附带票据的 DMG 作为候选分发方式；账户资格、证书和国内下载可达性在上线前实际验证。首次安装/更新签名失败不得引导用户长期关闭系统保护。首版手动下载更新，数据库迁移前自动备份并允许回退数据副本。

SwiftUI、Foundation、CryptoKit 为 Apple 平台 SDK，使用遵守 Apple 开发与分发协议，不能按通用开源包许可理解；SQLite 为 public domain。无需引入图像识别、照片解码或商业扫描 SDK；逐字节内容核对不需要 EXIF 解析。构建时记录 SDK、SQLite 版本与第三方清单；如后续增加封装库，逐项审查许可证及 NOTICE。

## 实施阶段、工时与验收门槛

以下为单名熟练开发者、已有 Mac 与外置盘的规划估算，不是报价或已批准排期。每周投入 20 小时。原研发 70 小时/约 5800 元情境不足以证明完整正式产品可交付，应单独重估；首两周 40 小时/外部现金 500 元只支持验证。

| 阶段 | 估算工时 | 出口条件（尚未执行） |
| --- | --- | --- |
| 技术验证 | 16–24 | 两块盘同名、克隆身份、授权撤销和中途拔盘样本跑通；确认原生与团队匹配 |
| 扫描与证据核心 | 48–72 | 所有 A01–A09 异常用例有记录；哈希匹配不会冒充逐字节一致 |
| 多任务、报告、恢复 | 24–40 | 重启恢复不串任务；损坏/未来版本备份拒绝且原库不变 |
| 真机容量、分发、修复 | 32–48 | 4 盘/10 万文件实测记录总字节、文件分布、设备、耗时、内存；签名安装及升级可重复 |

合计 120–184 小时，20 小时/周约 6–10 周；按内部核算 100 元/小时仅示例为 1.2–1.84 万元人工机会成本。另预留 500–2000 元现金情境用于盘线耗材/分发支出，不含购买 Mac；账户、证书等按实际渠道确认，无服务器固定费。12 个月支持另按每月 2–4 小时计，不能藏进原买断价利润。

工程目标：取消操作 1 秒内在界面显示“正在停止”；UI 不等待整盘完成才响应；实际停止读取受设备 I/O 影响。10 万索引列表首屏目标 1 秒内、扫描进程内存目标低于 512 MiB，均需指定设备实测后调整，绝不预设全盘扫描固定分钟数。只读验收用受控样本内容摘要、修改时间及文件写入审计证明无应用源文件写入。

## 上线前待核实

技术负责人确认 Swift 能力、最低系统与文件系统矩阵；产品负责人确认不支持图库包和 Windows 的对外文案；经营负责人确认新增工时与签名分发预算。这些执行条件不改变已采用的 macOS 技术路线；涉及新增预算或平台范围时另行登记变更。

## 官方依据（2026-09-20 核对）

- [Apple 卷 UUID API](https://developer.apple.com/documentation/foundation/urlresourcekey/volumeuuidstringkey)、[SHA256](https://developer.apple.com/documentation/cryptokit/sha256)、[macOS 公证](https://developer.apple.com/documentation/security/notarizing-macos-software-before-distribution)：官方入口已核对，但页面正文依赖 JavaScript；具体签名权限与 API 可用性还须在所选 Xcode SDK 实测，不将入口可访问当作通过验证。
- [SQLite online backup](https://www.sqlite.org/backup.html)：一致快照方案的依据；[SQLite 许可](https://sqlite.org/copyright.html)：public domain。
- [Tauri capabilities](https://v2.tauri.app/security/capabilities/)：备选可收窄 WebView 暴露的权限，但不能代替扫描核心自己的只读实现。
