## 每个项目怎样使用

每个项目按12个阶段独立建文件夹，项目首页只保留控制卡和导航：

```text
项目名称/
├── README.md
├── 00-项目管理/
├── 01-项目定义/
├── 02-商业与市场调研/
├── 03-商业模式与可行性评估/
├── 04-低成本验证/
├── 05-正式立项与实施规划/
├── 06-产品需求与版本规划/
├── 07-方案与详细设计/
├── 08-开发与实施/
├── 09-测试与业务验收/
├── 10-上线与交接/
├── 11-产品上市与商业启动/
├── 12-运营、迭代与收益复盘/
└── 99-历史版本/
```

每个阶段文件夹内已有：

| 文件 | 职责 |
| --- | --- |
| `README.md` | 本阶段目标、文件入口、前后阶段导航 |
| `01-阶段方案.md` | 项目专属任务、责任、业务细则及衔接 |
| `02-产出物与验收.md` | D01—D12各组的具体产出物清单、验收标准和执行记录 |

后续产出的调研报告、原型、需求、测试、上线和经营记录，继续保存在所属阶段，以产出物编号命名。真实客户资料放受控位置，在清单中引用证据；目录建立不代表这些结果已经取得。

原有客户访谈、商业参数、产品规则、测试用例和经营细则共248个章节已迁入对应阶段方案。原整篇资料移到各项目的 `99-历史版本/`，仅供追溯；`00-项目管理/`保留总体排期、台账入口和逐章迁移索引。
