# 国内市场优先：全生命周期项目方案 V3

编制：2026-09-20｜交付性质：经营与产品实施设计｜状态：未执行访谈、开发、收费或上线。

本批将已有中国市场Top10按项目负责人视角统一为“商业调研—低成本验证—立项—需求设计—实施验收—上线交接—上市运营—收益复盘”的全生命周期方案。每一步明确产出物、责任角色与通过条件。范围是原40项中选出的10项，不等于全部国内机会；C21科技人物内容账号虽面向国内受众，属于后增方向，本批暂未展开，留待本批完成后确认。

用户明确要求国内市场优先，至少包含商业、产品、交付，并单独建文件夹。沿用既有条件：没有现成客户渠道、兼顾服务和标准产品。可投入时间、预算与专业能力尚未确认；下列时间、价格、成本、转化和验收门槛均为计划假设，实际执行后更新。

## 每个项目怎样使用

每个目录共6份文件：

| 文件 | 职责 |
| --- | --- |
| `README.md` | 项目入口、核心验证问题和启动边界 |
| `00-全生命周期主计划.md` | 主计划：12阶段、D01—D12产出物、负责人和验收角色、R1—R5决策、上市运营及收益跟踪 |

| `02-客户开发与成交.md` | 客户筛选、渠道、访谈、演示和成交细则 |
| `03-产品流程与验收.md` | 数据、规则、异常用例与质量细则 |
| `04-试点排期与经营复盘.md` | 原试点排期、交付包、指标和经营判断 |

先读00主计划，在到达对应阶段时查01—04细则；不要把方案文档当成实际交付证据。各项目已有公开研究，但尚无本轮客户验证、实现、收费及上线结果。12阶段采用统一结构，服务、网页软件及本地工具分别适配产出物；“上市”指产品或服务市场启动。
