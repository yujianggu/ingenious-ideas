## 后续扩展

中国大陆专题已建立。形成实质研究后，再增加“美国.md”和“欧洲/”下的总览、德国、法国、荷兰等专题。当前欧洲样本不代表全欧洲，也不意味着优先进入这些国家。

国家页应说明客户分层、渠道、支付、竞争与替代、本地化、交付约束、适合验证的创意及反证，并引用共用证据和创意档案。国家事实更新时改对应专题；具体产品判断变化时同步更新原创意档案。来源和实验不在国家页重复保存。

当前资料仍为桌面研究。创意P级表示研究顺序，市场M级表示当地验证进度，不能互相替代。
