## 本轮分析口径

每个档案覆盖：案例证据、客户与购买、产品流程、最小可售产品、AI与人工分工、商业模式、成本算例、获客留存、替代方案、市场适配、两周验证和未知项。

**[事实]**指来源实际陈述，仍需注意自述或估算属性；**[推断]**是研究判断；**[假设]**是待验证的设计、定价、成本和门槛。所有新项目成本算例均为情境推演，贡献额不是净利润。尚未执行对外访谈、收费或试点。

P1是满足资源前提后可试单的候选，P2是观察项，P3是优先补证项。没有任何一项因外部案例收入而获得“市场已验证”的结论。
