## 分析口径

每份档案采用十二项商业分析：判断、证据、买家、流程、最小产品、单位经济、获客留存、竞争、风险、验证、未知项与来源。新增档案明确标注AI研发角色、无模型核心边界、前期研发和持续维护成本。

**事实**是来源实际陈述，仍保留自述属性；**推断**是研究判断；**假设**是待验证设计、成本和实验门槛。Reddit求助、点赞、愿付费与创始人推广不等于真实成交；所有人民币经营算例均为假设，贡献不是净利润。

P1为有资源前提的低成本验证候选，P2需先厘清障碍，P3先补关键证据。编号固定、不表示排序。P级不代表某国家已验证；41项地区进入状态均仍为M0，需按国家／语言、客户、渠道与交付方式分别核实。新增20项核心无须AI是拟议产品要求，还没有实现或通过关闭模型测试。
