# 从桌面研究到付费验证

状态：计划，未实施；更新：2026-09-19。

当前已收集的是外部案例和产品信息，没有自己的客户访谈或交易数据。下一步一次选择一个主方向，最多保留一个备选，避免同时试做20项。

## 选择前先补齐资源

明确四项：主要市场与语言、两周可投入时间、可承受的试验支出、能接触到的第一批目标客户。哪一项已有客户入口，往往比案例历史营收高低更能影响验证顺序。

| 已有资源 | 可先看 | 应先排除的障碍 |
| --- | --- | --- |
| 求职社群或招聘经验 | C01 | 无法取得真实岗位和求职经历 |
| 语言教学能力或社群 | C03 | 无人审校情境与反馈质量 |
| 礼物内容渠道与印刷合作 | C04 | 不能按期交付合格样书 |
| 中小企业客服资源 | B01 | 没有可授权试用的知识资料与工单 |
| 培训客户或教材资源 | B05 | 缺少购买者或审题人 |
| 本地商家关系与交付能力 | B06 | 商家并不需要独立网站入口 |

## 两周共通节奏

1. 第1–3天：访谈近期发生需求的目标用户，收集现有交付物和开支。把“谁买、什么结果、何时交付”写成一页说明。
2. 第4–6天：人工辅助制作一份完整样品，统计真实耗时与成本，测试用户能否判断好坏。
3. 第7–10天：向合格对象展示明确报价，记录实际购买。先交付有限批次，执行各创意档案预设的质量门槛。
4. 第11–14天：复盘退款、修改与耗时；给出继续、调整或暂停决定。订阅产品另设30天或更长观察期，两周内不宣称已证明续费。

本计划不包含已经授权的对外联络、收费或广告投放，当前没有执行这些活动。后续选择方向后，再落实具体对象、预算与交付安排。

## 共同反证

- 用户已有廉价替代方式，样品没有显著减少任务成本或提高可用性。
- 愿意试用的人很多，看到清楚报价后没有真实购买。
- 算上直接人工和返工后，每多交付一单就多亏一单。
- 必须依赖尚不存在的数据访问、行业伙伴或复杂集成，才能交付核心价值。

以上是需要调查的问题，不是当前20项已经失败的结论。
