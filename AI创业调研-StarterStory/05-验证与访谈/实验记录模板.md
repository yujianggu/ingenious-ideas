# 实验记录模板

本文件为模板，不代表已执行。

| 字段 | 填写内容 |
| --- | --- |
| 实验编号 | EXP-创意编号-顺序号 |
| 关联档案 | 对应创意的相对链接 |
| 状态 | 计划 / 执行中 / 已结束 |
| 周期与负责人 | 实际起止日期与负责人 |
| 最危险的假设 | 只选一项，如客户是否愿为成品付费 |
| 目标客户与排除条件 | 具体场景、已有需求及不接受样本 |
| 样本与渠道 | 计划/实际人数、来源、熟人占比 |
| 报价与交付 | 价格、付款条件、交付物、修改次数 |
| 继续标准 | 实验开始前写明数量、比例、质量与成本要求 |
| 停止标准 | 哪些结果足以推翻本轮假设 |

## 实际结果

尚未执行。执行后填写接触人数、合格人数、看到报价人数、付费人数、交付人数、退款人数；所有比例保留分母。

## 交付与成本

逐单记录到账、模型/工具、直接人工小时、支付费、返工、退款、获客费用。分别计算交付贡献与扣获客后贡献，写清未计入项目。

## 访谈记录

记录最近一次真实问题发生的时间、当时如何处理、花费多少时间和钱、谁决定购买，以及交付样例评价。区分原话与研究者解释，不把“愿意试试”当购买证据。

## 判断与后续

继续 / 调整 / 暂停，附依据、反例、样本偏差、尚未覆盖的问题。更新关联档案和比较表。
